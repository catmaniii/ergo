# Codex

这台电脑上装了 Codex 的，可以让任务、项目的负责人用它干活。用你自己的 Codex 配置和登录；二狗照样记下它的工具调用，有风险的照样拦下或者问你。少数几样拦不住，下面照实写了。

已经在终端里用着的 Codex 会话，也能交给二狗接着做，做完再交回终端。

只有任务、项目的负责人能用 Codex。秘书不能换。

## 用之前要准备什么

1. 装 Codex：`npm i -g @openai/codex`。版本要 0.166.0 或更新。
2. 登录：在终端里跑 `codex login`。二狗不看你的登录信息，用的是 Codex 自己的登录。
3. 打开 **设置 · 能力 · 插件**，找 Codex。写「运行中」就好了。写「没装」时下面一行写着缺什么，装好后点「启用」。

做完以后，发起任务和新建项目的对话框里，「运行时」一排多一项 **Codex**。

**要知道的**

- 没装时，别的功能不受影响。还有别的运行时能选的话，「运行时」里的 Codex 是灰的，点一下写明怎么装。
- 没登录时，这一轮按出错收尾，写明要跑 `codex login`。登录后再发一条消息接着做。
- 插件停用后，用 Codex 的负责人不再启动。正在做的任务转成「等我」，启用后接着做。

## 新建一个用 Codex 的任务或项目

和 [Claude Code](claude-code.md#新建一个用-claude-code-的任务) 一样：

1. 点「＋ 发起任务」或「＋ 新建项目」，写清楚要做的事。
2. 「运行时」点 **Codex**。下面多出「从 Codex 会话接管…」和「在哪个文件夹做」。
3. 「在哪个文件夹做」选在默认文件夹下新开，或者用已有的文件夹。默认文件夹在 **设置 · 能力 · Codex** 里定。
4. 点最下面的按钮。卡上标着「Codex」。

## 接管已有的会话

**这是什么：** 你在终端里用 Codex 做到一半，想让二狗接着做。工作目录和之前聊到哪都照原来的。

**在哪里打开：** 发起任务或新建项目的对话框，「运行时」选 Codex 后，点「从 Codex 会话接管…」。

1. 列出这台电脑上的 Codex 会话。每行写标题、工作目录、分支和最近活动。二狗自己开的不列。
2. 点选一个会话，看这一行的小签：
   - **占着**：Codex 说它开着，或者几分钟前还有活动。先去那边关掉再点「刷新」，或者勾「分叉一份接管（原会话不动）」。
   - **可能开着**：判不准。Codex 不告诉别人谁开着一个会话，终端开着没说话的看不出来。所以默认勾着分叉；确认那边关了，可以取消勾选直接接。
   - **在管**：二狗的另一个任务或项目在管。要接只能勾分叉。
3. 接成任务时写「接着让它做什么」；接成项目时可以空着。
4. 点「接管」或「分叉接管」。

会话里先列出前情：Codex 那边最近的一段对话，只给你看，不算新的输入。

**要知道的**

- Codex 的会话没有锁。两边一起写会分叉，丢掉一边说的话。接管期间终端里别再打开它。
- 分叉出来的是新会话，原来的不动。

## 交还给终端，再收回来

**在哪里打开：** 任务详情或者项目负责人会话的标题栏，点 ⚙，找「运行时」这一块。

1. 点「交还给 Codex」。这时二狗不写这个会话。
2. 回终端跑 `codex resume`，接着用。
3. 用完了，先在终端里关掉，再回 ⚙ 点「收回到二狗」。

**要知道的**

- 收回前二狗按状态和最近活动核对。交还之后那边动过、几分钟内还有活动的不收回，写明原因。过一会儿再点。
- 开着但一直没说话的终端看不出来。确认关了再收回，不然两边一起写会分叉。
- 撤回过的话，二狗接着的是分叉出来的新会话，`codex resume` 里要选那一个。

## 选模型、沙箱、思考档位

**在哪里打开：** ⚙ · 运行时。默认都是「跟 Codex 自己的设置」。

- **模型**：列表是 Codex 自己报的。负责人第一次起来之前是空的。换了模型的，旧模型写一份交接摘要，新模型新开一段会话接着。
- **沙箱**：只读、只能写工作目录、不用沙箱（只靠守卫）。
- **思考档位**：低、中、高、很高。

审批策略不是选项：二狗固定用最严的，要过守卫。

## 守卫管到哪

每次命令、改文件、调 MCP 工具都先过二狗的守卫，判不放行就不执行。工具调用的参数和结果都记进二狗。

**这几样拦不住，只能事后知道：**

- 钩子没管到、Codex 又判成只读不问的命令：已经跑了才记下。判了不放行就打断这一轮。
- Codex 自己看图、写计划清单、找工具、读 MCP 资源、等一会儿：事后记录。
- 生成图片：在模型服务那边做，事后记录，判了不放行就打断。
- 派子代理：事后记录。子代理里的命令、改文件照常过守卫。

Codex 自己的联网搜索关掉了，因为它在模型服务那边做，拦不住。要联网的负责人用二狗的联网搜索，调用之前过守卫。联网开关关着的就不能搜。

审批被拒时，Codex 只知道被拒了，不知道为什么。钩子拦下的说得清原因。

## 花的钱

- ChatGPT 账号登录的用订阅额度，消耗页写「用订阅额度、不算钱」。
- API key 登录的按量计费，实际花了钱。消耗页写明没有单价、以服务商账单为准，不算成本不等于免费。
- 交给 Codex 的环境去掉了 `OPENAI_API_KEY`、`CODEX_API_KEY` 这些变量，不会悄悄改计费方式。
- 额度用完时这一轮出错，任务转「等我」，写明额度用完。等额度恢复后再发一条消息接着。

## 撤回

会话缩小后，条左边的 ↶ 照常能点。Codex 从那条之前分叉出一个新会话接着做，原来的留着，成了一条能切回去的废弃分支。

**只回对话，不恢复文件：** 它改过的文件留着，撤回确认框里也写着。只能回到一条消息之前，回不到阶段、步骤开始前。接管之前的对话撤回不到。

## 要知道的

- 二狗的工具（提交计划、汇报进展、发附件、联网搜索、工具包里的 MCP）它都能调，每次过守卫。
- 工具包里的 skill 复制一份交给它，原件不动。输入框打 `/` 列的是二狗的命令和 skill，Codex 终端里的斜杠命令这里用不了。
- 二狗不读你的 `~/.codex`，也不写它和项目配置。
- 工具包改了不会当场换：这一轮做完，按新的工具包重新起。
- 不能交给 Codex 的官方 App。秘书、子 agent、评审还是 pi。
