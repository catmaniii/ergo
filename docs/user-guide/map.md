# 看地图

二狗里有一张地图：在国内看高德地图，出了国（比如在新加坡）填了谷歌的 Key 看谷歌地图、没填看高德地图，看到哪里自动换；地图页、足迹、聊天里地图卡片的预览图用的都是同一家。你某一天去过哪里、在哪待了多久、照片在哪拍的都能画在这张地图上；跟二狗说"把我今天去过的地方画在地图上"，聊天里就出一张地图卡片。你还可以直接问二狗"从家到公司多久""附近有什么咖啡店"，它替你去查：国内用高德，国外用免费的 OpenStreetMap（填了谷歌的 Key 用谷歌），查到的地点、路线也能放成卡片。

看完这一章你会知道：地图页在哪、在地图上怎么和二狗说话、怎么看某一天的足迹、聊天里的地图卡片、怎么让国内的地图更清楚（填高德的 Key）、国外怎么用谷歌地图（在 Google Cloud 建 Key、防止扣钱）、怎么让二狗查地点和路线、地图服务能看到你的什么。

## 打开地图

**在哪里打开：** 导航里的「地图」。手机上放不下时在「更多」里。

- 拖动挪地图，两个手指捏合（电脑上滚轮）放大缩小，双击放大一级；右上角也有放大、缩小的按钮。
- 标题栏只有一行：「地图」、（「足迹」开着时）选日期的那一组、最右边依次是选地图（「地图：自动」，手机上是 ⋮）、「足迹」开关和二狗按钮，地图尽量多露出来。
- **回到我现在的位置**：右下角二狗按钮上面那个准星按钮（高德地图、OpenStreetMap 上都有）。点了地图挪到你现在在的地方、放大到能看清街道，画一个圆点；知道定位有多准时，圆点外面再画一个淡淡的圈（你就在这个圈里）。一分钟内再点一次直接回到那里。位置从哪来：
  - 在鸿蒙手机的二狗 App 里，用 App 自己的定位（第一次会问你给不给定位权限）；
  - 在浏览器里（电脑上打开 `http://127.0.0.1:8810`、或者 https 的地址），用浏览器的定位，浏览器会问你允不允许；
  - 这台设备拿不到位置时（没给权限、等了 10 秒没定到、安卓 App 和局域网地址用不了网页定位），退一步用手机最近交来的那个位置，地图下面写一句「没拿到这台设备的位置，这是 12 分钟前手机交来的位置」，圆点旁边写几点交来的；手机也没交来过就写「拿不到你现在的位置」。
  - 你现在的位置只在这一页里用：不存（下次打开地图回到的是你上次自己看的地方，不是定到的位置）、不发给二狗以外的地方。看的是高德地图时，和平时看国内地图一样，高德知道你在看哪一片（见下面「地图服务能看到你的什么」）。
  - 定到的地方不在中国大陆时，地图换成国外的当前地图（见下面）。
- 左上角写着现在用的是哪种地图：「高德地图」「谷歌地图」或「OpenStreetMap」。
- 看的地方停下来时自动挑：**在中国大陆**，填了高德的 Key 用高德地图，没填用 OpenStreetMap；**国外、香港、澳门、台湾**，填了谷歌的 Key 用谷歌地图（见下面「国外用谷歌地图」），没填用高德地图，高德也没填才用 OpenStreetMap。那一家在这台设备上加载不了（连不上、Key 被拒）时也退到下一家。高德的国外地图是它的「世界地图」能力，要在高德开放平台提工单开通；没开通时国外可能只有很粗的地图，嫌空可以在「地图：自动」里给国外选 OpenStreetMap。
- **当前地图**：国内、国外各一家——你在「地图：…」里选了哪家就是哪家，没选就是上面「自动」挑的那家。地图页、开着「足迹」的地图、聊天里地图卡片的预览图都用它当底图（点和线二狗自己画在上面）。只有一个例外：高德、谷歌查来的地点和路线（它们的规定）永远画在查它的那家地图上，见下面「聊天里的地图卡片」。
- **自己选用哪家地图**：标题栏右边那一组最前面的「地图：自动」（手机上收在 ⋮ 里）。点开列着现在看的这一边（国内、国外）能用的几家：「自动」，再加上填了 Key、Key 没坏的那几家，「自动」会挑的排前面、只能手动选的排后面——国内是高德地图、OpenStreetMap、谷歌地图，国外是谷歌地图、高德地图、OpenStreetMap（谷歌要填了它的浏览器用的 Key 才列，高德要填了 Web 端的 Key 才列）。选了就一直用它，记在这台设备上，**国内选的和国外选的分开记**；选回「自动」就照上面的规矩挑。你选的那家后来用不了了（Key 坏了、插件停了、这台设备连不上），地图自动换回「自动」，下面说一句「…现在用不了，换回了“自动”」。这台设备连不上的那一家在列表里标「连不上」。列表最后一句写着：地图页、足迹、聊天里的地图卡片都用这一家当底图，查地点、算路线也先用它；足迹和二狗画的点、线只在这台设备上画，这一家只知道你在看哪一片。
- **看足迹也用当前地图**：标题栏右边的「足迹」开着时，足迹画在当前地图上面（国内一般是高德地图），开关「足迹」不换地图。**足迹只在这台设备上画**：二狗在地图上面盖一层自己的，把轨迹、停留、照片地点画在这一层上，不交给高德、谷歌——它们只看得到你在看哪一片地图，见下面「地图服务能看到你的什么」。「足迹」默认关着。
- 高德、谷歌的地图程序还在加载时，地图那块先空着、写「正在加载高德地图…」，不先闪一下 OpenStreetMap；加载失败或者 20 秒还没加载上，才退到下一家。
- 下次打开还在你上次看的地方（记在这台设备的浏览器里）。
- 用 OpenStreetMap 时右下角写着「© OpenStreetMap 贡献者」；高德地图自己在角上印着它的标志和审图号。
- 深色外观下地图也是暗的。

## 在地图上和二狗说话

地图页里的二狗就是平时的二狗：和「秘书」页、「浏览」右边的侧边栏是同一段对话，在这里说的话那边也看得到。不同的是，从地图页说的每句话都带着**你在地图上看的是哪里**——地图的中心、放大到几级、用的是哪家地图（高德、OpenStreetMap，或者你装的别的地图插件）、正在看哪一天的足迹（选中了哪一处）、看的是哪张地图卡片。所以可以直接说"这附近有什么好吃的""把这条路线画出来""我那天在这儿待了多久"，二狗知道"这里"指地图上的这一片（不是你本人的位置——你的位置不带过去），查地点、算路线也先用你地图上正用的那一家（比如在国外你选了 OpenStreetMap，就用它查；开不开「足迹」都一样。国外地图是高德时用 OpenStreetMap 查——高德只查国内——查到的照样画在高德地图上），要给你看的地点、路线会画成地图卡片。

- **右边的聊天窗**：点标题栏最右边的二狗按钮打开、再点收起。电脑上（地图页够宽）它在右边，地图让出地方、不被盖住，中间的分隔条拖着能调宽窄；手机上它盖住整个地图页，点顶上的「›」或者手机的返回收起。开着还是收着、拖到多宽，都记在这台设备上，下次打开地图照上次的样子。
- **右下角的二狗按钮**：聊天窗收着时地图右下角有个二狗的圆按钮（和「浏览」里网页上的那个一样），「回到我现在的位置」在它上面。点一下，按钮上方出一个小框打字；按住说话，松开发出去，手指往上滑再松开是取消（语音插件停用时只能打字）。二狗的回话短短一两句显示在小框里，也在对话里；小框右上角「展开到右边」打开右边的聊天窗看完整的对话。聊天窗开着时不显示这个按钮。
- 在对话里，地图页发的那句下面写着「在地图上说」或「在地图上用悬浮按钮打字 / 说」。

## 我的足迹：某一天去过哪

手机上的二狗 App 开始记位置（设置 · 数据源 ·「手机 · 位置」，在 App 里点「开始记位置」）、连上相册以后，地图页能画出某一天的足迹。

- **打开**：标题栏右边的「足迹」（手机上是一个定位针图标），默认关着；点一下地图上画出这一天、挪到看得全它的地方，选日期的那一组出现在标题栏里。再点一下关掉（记在这台设备的浏览器里）。
- **选哪一天**：在标题栏里，「地图」两个字后面：左右箭头是前一天、后一天，中间点开选日期，再后面写着这一天的概况（「待过 3 个地方 · 6 张照片」）。手机上放不下整句，日期写成「11/07」，概况写成「3 处 · 6 张」，「足迹」开关只剩一个定位针图标。打开地图时看今天；今天还没有足迹就自动跳到最近有足迹的那一天。某一天什么都没有时写「这一天没有足迹」，旁边的按钮跳到它之前最近有足迹的一天。
- **地图上画的**：
  - 一条线：这一天按时间连起来的位置。在一个地方待着的那一段收成一个点，不画成一团；中间一个半小时以上没记到的地方断开，不把没记到的那段画成直线；
  - 定位针：在哪儿**待过**——一串位置都在 400 米以内、待够 15 分钟算一处（和记忆里每天那条位置摘要同一个算法）。旁边写名字和一共待了多久：起了名的（「家」「公司」）写名字，没起的写手机转出来的地名，都没有的写几点到的。同一处去了几次（早上在家、晚上又回家）只有一个针；
  - 空心小圆点：照片在哪拍的，旁边写几点拍的；挨着拍的（半小时以内、百米以内）合成一个点，写拍了几张。只有时间和地点，**不放照片**；
  - 圆圈：你起了名的常去的地方的范围。这一天没去的那几处圈里写着名字。
- **看详情**：电脑上地图左边列着这一天（每段停留几点到几点、待了多久，不在停留时拍的照片），点一行跳过去，点停留在下面展开详情；手机上点定位针，地图下面出一张卡，点那一条里的「待过 3 个地方……」看这一天的列表。
- **收起、关掉**：电脑上左边那一栏顶上有「收起」和「×」——收起后缩成左上角一个「这一天」小按钮，点它再展开；关掉后点标题栏上的「待过 3 个地方……」再打开。手机上下面那张卡是个抽屉：顶上的小横条往下拖（或点一下）拖低到只露标题那一行，再往下拖关掉，往上拖拉高。收起、关掉、拖低都记在这台设备上。详情里写这一处叫什么、地名、每次几点到几点、一共待了多久、在这里拍了几张照片。没起名的有「去起个名字」，到 设置 · 数据源 ·「手机 · 位置」的「常去的地方」里起。
- 聊天里的足迹卡片点开就是这一页，看的是那一天（「足迹」关着也会打开，不改你记着的开关）。

足迹是你电脑上的二狗按你手机交来的位置现算的，算的时候不联网；只在这台设备上画在当前地图上面，不交给高德、谷歌，见下面「地图服务能看到你的什么」。

## 聊天里的地图卡片

跟二狗说"把我今天去过的地方画在地图上""昨天去了哪"，它先用一句话说结论（"去了 3 个地方：公司、西湖边、家"），聊天里再出一张**地图卡片**。用语音问也一样：念给你听的是结论，地图在卡片上。

- **足迹卡**：标题写哪一天（"11 月 6 日去过的地方"），下面一块预览图画着那天的轨迹和停留的几处，再下面写"待过 3 个地方 · 6 张照片"和去过的几处。预览图不能拖，点它右上角的「看大地图」进地图页看那一天。
- **查到的地点和路线**：让二狗查"从公司到西湖边怎么走""附近的咖啡店"以后，它可以把结果放成一张卡。高德、谷歌查来的**只能画在它自己的地图上**（它们的规定），所以卡上的预览图是查它的那家的地图（不管你选的是哪家），画着查到的几处（标着序号）或路线，下面写走法（步行、开车……）或查到的几处，写着「数据来自高德地图」；点「看大地图」进地图页，用高德地图画出来。预览图取不到时（谷歌的 Maps Static API 没开、超了免费量、那一家出错），卡上只有字，加一句「预览图没出来：…」和「在高德地图上看」。查到的结果只在电脑上留一会儿、不存（高德不许存），过一阵子再点卡片写"已经过期了"，再问一次就有。OpenStreetMap 查来的（国外没填谷歌，或者没填高德 Key 时的国内）哪家地图上都能画，预览图和足迹卡一样用当前地图，写着「数据来自 OpenStreetMap」，同样只留一会儿。
- **二狗标的点、画的路线**：它说"西湖和灵隐寺在这儿"时也会出卡片，画法和足迹卡一样。
- **预览图用哪家**：足迹卡、二狗标的点和路线、OpenStreetMap 查来的，用卡上内容所在那一边（国内、国外）的当前地图；高德、谷歌查来的用查它的那家。是高德、谷歌时，电脑拿你填的 Key（高德用 Web 服务 Key，谷歌用服务端用的 Key）向它要一张**光底图**——只说要哪一片（中心、放大到几级、多大、深浅），不带一个点、一条线，Key 不进网页；聊天滚到卡片附近才去要，图不存。点（标着序号，几个都画）和线由页面自己画在这张图上面，地图公司的标志和版权那一条不盖。高德的图没有深色，深色外观下压暗一点；谷歌的取深色的。当前地图是 OpenStreetMap、或者高德谷歌的图取不到时，足迹、点、路线由页面自己画在 OpenStreetMap 上。
- 在地图页看一张卡片时，标题栏里写卡片的标题和概况，点「×」回到地图。
- 点开高德、谷歌查来的卡片时，地图这一屏临时用查它的那家画（你记着的选择不变），地图上面写一句「这些是高德地图查的，所以用高德地图显示」；点「×」不看这张了，换回你的当前地图。那家在这台设备上加载不了（比如在国内连不上谷歌）时，地图那块先放一张这张卡的静态大图，写「这台设备连不上谷歌地图，先给你看一张图」；大图也取不到时说一句为什么画不上去。
- 「浏览」右边的侧边栏里点卡片也一样：侧边栏收起，切到地图页看这张卡。
- 在「浏览」里选中网页上的地址点「在地图上看」，不出卡片，直接切到地图页看找到的那一处（标题栏写你选的那段字），见[内置浏览器](browser.md#选中地址在地图上看怎么去)。

卡片上只存日期（足迹每次打开现取，手机那边删了卡上也跟着没了）、查询的编号，或者二狗给的那几个点。

## 让国内的地图更清楚：填高德的 Key

没填 Key 时国内也用 OpenStreetMap，地图下面写一句「填了高德 Key 国内地图更清楚」，点「去填」就到填 Key 的地方。

**在哪里填：** 设置 · 数据与设备 · 数据源，点「高德地图」。

1. 在高德开放平台（lbs.amap.com）注册、做个人认证，进控制台建一个应用；
2. 在应用下面添加 Key，服务平台选「Web端(JS API)」。建好以后同一个 Key 下面有一串「安全密钥」；
3. 把 Key 和安全密钥填进「Web 端（JS API）Key」「安全密钥」两个框，点「测试并保存」。二狗拿它们问一次高德（问的是北京天安门这个固定的点，不是你的位置），高德说对了才存下；
4. 「Web 服务 Key」选填：让二狗查地点、算路线时要它（见下一节），聊天里地图卡片的高德预览图（静态地图）也用它；在控制台另建一个服务平台是「Web服务」的 Key。

填错了会写原因：Key 不对、安全密钥不对、Key 的服务平台选错了。以前存过的、新填的没通过，照旧用以前的。

Key 和安全密钥只存在这台电脑上。安全密钥不发给网页：高德的地图要它的那些请求，由二狗在电脑上替网页拼上再转给高德。

不想用了：在「高德地图」里点「断开」，Key 和安全密钥从这台电脑上删掉，国内改用 OpenStreetMap（国外没填谷歌时也是）。

高德的地图在国外也能看：国外没填谷歌时「自动」就用它。国外的详细地图是高德的「世界地图」能力，要在高德开放平台提工单开通；没开通时国外可能只有很粗的地图，在「地图：…」里给国外选 OpenStreetMap 就好。高德查地点、算路线照旧只管国内。

**高德 Key 的几条规矩**（照高德开放平台的[服务协议](https://lbs.amap.com/home/terms/)，2025-12-03 版）：

- Key 要你自己在高德开放平台申请（做个人开发者认证），二狗不带现成的 Key、也不和别人共用。你的 Key 也别给别人用：协议 4.5 写着不得转让、出租、出借。
- 个人开发者的 Key 适合个人自己用、不拿来赚钱（协议 3.1 写的是"个人研究学习目的"）。要在公司、组织里部署二狗，或者拿二狗给别人提供服务，要用企业认证、向高德买商用的使用许可（协议 3.2）。
- 高德不许存、不许缓存它查到的结果（协议 3.5），二狗查到的只现用、不存。高德的结果画在高德地图上、写明来自高德（协议 4.12.4、7.7）：国内的地图页本来就是高德地图，回答里也写着"数据来自高德"。

## 国外用谷歌地图：填谷歌的两个 Key

装着「谷歌地图」插件（默认就有）、填了谷歌的 Key 以后：

- 地图页看**中国大陆以外**时自动用谷歌地图（左上角写「谷歌地图」），比高德的世界地图、OpenStreetMap 的店名、门牌全；
- 问二狗大陆以外的地点、路线时用谷歌查：**有公交地铁的换乘方案，开车的用时带现在的路况**，"附近的 hawker centre"按远近列出来，回答里写明"数据来自 Google 地图"；
- 地图切换（「地图：…」）里**国内国外都能选「谷歌地图」**：在国内选了它也能用（二狗自动转坐标：谷歌在国内的街道图和高德一样用的是偏移过的坐标）。这台设备在国内连不上谷歌时，切换里标「连不上」，地图下面说一句、换回「自动」。查地点、算路线是电脑去问谷歌，电脑的网络能连上谷歌就能查。
- 聊天里谷歌查的卡片有谷歌的预览图（要多开一个 Maps Static API，见下面第 3 步），国外的足迹卡、点和路线的卡片也用谷歌的预览图（只向谷歌要光底图，点和线页面自己画）；开着「足迹」时足迹也画在谷歌地图上面（只在这台设备上画）。

没填 Key、停用了插件、超了免费量时，国外用高德地图（高德也没填用 OpenStreetMap）。

**在哪里填：** 设置 · 数据与设备 · 数据源，点「谷歌地图」。要填两个 Key：

- **浏览器用的 Key**：给地图页的谷歌底图（Maps JavaScript API）。谷歌的设计里它要放进网页，别人打开网页的源代码看得到，所以一定要在 Google Cloud 里给它加「网站限制」（下面第 5 步）。谷歌只让在网页里测它：存的时候只看写法，地图页第一次用上谷歌底图时才知道对不对；不对的话谷歌会拒绝，地图换回「自动」的下一家（高德或 OpenStreetMap），「谷歌地图」那一行写"要授权"，改好后重新填一次。
- **服务端用的 Key**：给二狗查地点、算路线（Places API (New)、Routes API、Geocoding API），还有聊天里地图卡片的预览图（Maps Static API）。只存在这台电脑上，不进网页。点「测试并保存」时二狗拿它把这三个 API 各问一次（问的是新加坡鱼尾狮公园这个固定的地方，不是你的位置），三个都通了才存；哪个 API 没开、Key 的限制不让，写明是哪一个、怎么改。接着再取一张很小的静态地图试 Maps Static API：它没开不挡保存，只在下面标「卡片预览图（Maps Static API）：没开」，聊天里谷歌查的卡片先只有字。以前存过的、新填的没通过，照旧用以前的。

两个 Key 可以只填一个：只填浏览器用的，地图页用谷歌底图、查询还是 OpenStreetMap；只填服务端用的，查询和卡片的预览图用谷歌、国外地图页的底图是高德或 OpenStreetMap（谷歌查来的地点、路线只能画在谷歌地图上，点开这种卡片时地图页说一句为什么画不上）。

### 在 Google Cloud 开 API、建 Key、防止扣钱

谷歌地图要求项目开结算（绑一张卡），每个月每一项有一份免费量，超出的按量收费。二狗不碰你的付款信息；下面这些在 Google Cloud 控制台（console.cloud.google.com）里由你自己做，**第 7、8 步请一定做**：

1. **建项目**：控制台左上角选项目 →「新建项目」，起个名字（比如 ergo-maps）。
2. **开结算**：左边菜单「结算」，给这个项目关联一个结算账号（没有就按提示建一个、绑卡）。谷歌要求有结算账号才能用地图服务。
3. **开五个 API**：「API 和服务 · 库」里搜着开：**Maps JavaScript API**、**Places API (New)**（注意是带 New 的那个）、**Routes API**、**Geocoding API**、**Maps Static API**（聊天里地图卡片的预览图）。
4. **建两个 Key**：「API 和服务 · 凭据」→「创建凭据 · API 密钥」，建两次，分别改名叫"ergo 浏览器"和"ergo 服务端"。
5. **给浏览器用的 Key 加限制**：编辑"ergo 浏览器"——
   - 「应用限制」选「网站」，加你打开二狗用的地址，每个一行：本机的 `http://127.0.0.1:8810/*`、`http://localhost:8810/*`，在外面打开二狗用的地址（比如 `https://你的外网地址/*`）；在别的电脑、手机上用局域网地址打开的，也把那个地址加上。设置 · 数据源 · 谷歌地图里写着这台设备打开二狗用的地址。
   - 「API 限制」选「限制密钥」，只勾 **Maps JavaScript API**。
6. **给服务端用的 Key 加限制**：编辑"ergo 服务端"——
   - 「应用限制」选「IP 地址」，写这台电脑上网的出口 IP（搜"我的 IP"能看到；家里宽带的 IP 会变，变了要回来改，嫌麻烦可以先不加，但 API 限制一定要加）；
   - 「API 限制」选「限制密钥」，只勾 **Places API (New)**、**Routes API**、**Geocoding API**、**Maps Static API**。
7. **设预算提醒**：左边菜单「结算 · 预算和提醒」→「创建预算」，选这个项目，金额写一个你能接受的小数（比如 1 美元），提醒阈值留 50%、90%、100%。**预算只发邮件提醒，不会自动停掉服务。**
8. **设每日上限（真正挡住扣钱的是这一步）**：「API 和服务」里点进每个 API →「配额和系统限制」，把"每天的请求数"（Requests per day）改小。谷歌建议按"每月免费量 ÷ 31"设，到了上限当天就查不了、第二天恢复，不会多扣钱：

   | API | 每月免费量（2026-11，以控制台为准） | 建议每日上限 |
   |---|---|---|
   | Maps JavaScript API | 地图加载 10,000 次 | 300 |
   | Places API (New) | 搜地点（Text Search Pro）5,000 次、周边（Nearby Search Pro）5,000 次 | 150 |
   | Geocoding API | 10,000 次 | 300 |
   | Routes API | 步行和公交（Compute Routes Essentials）10,000 次、开车带路况（Compute Routes Pro）5,000 次 | 150 |
   | Maps Static API | 静态地图 10,000 次 | 300 |

9. 把两个 Key 分别填进 设置 · 数据源 · 谷歌地图，点「测试并保存」。

**以前填过 Key、那时还没有卡片预览图的**：在 Google Cloud 补开第 3 步的 **Maps Static API**、在第 6 步服务端 Key 的「API 限制」里补勾它、第 8 步给它也设每日上限，再到 设置 · 数据源 · 谷歌地图 点一次「测试并保存」，服务端 Key 下面那一行变成「卡片预览图（Maps Static API）：能用」。不补也照常用，只是谷歌查的卡片只有字、国外的卡片用高德或 OpenStreetMap 画。

### 用量和超了怎么办

二狗按谷歌的计费项记着每个月用了几次（只记次数，不记查了什么）：地图加载、搜地点、周边、地址和位置、步行和公交路线、开车路线、卡片预览图。设置 · 数据源 · 谷歌地图里列着"这个月用了几次 / 每月免费量"，体检的「地图」那一块有「谷歌地图的用量」。

- 哪一项到了免费量的八成，体检提醒；
- **哪一项到了免费量，二狗先停用谷歌**：地图加载超了，地图页在国外改用高德地图（没填高德用 OpenStreetMap）；查询的哪一项超了，二狗查地点、算路线改用 OpenStreetMap，回答里说一句；卡片预览图超了，聊天里的卡片改由页面自己画 OpenStreetMap（谷歌查的只写字）。下个月自动恢复。
- 想超了也接着用：在「谷歌地图」里勾「超了免费量还接着用」，超出的谷歌按量收费（体检照样标红提醒你）。

二狗数的次数和谷歌的账单不一定完全对得上（谷歌按太平洋时间算月份，测 Key 时那几次也算），以 Google Cloud 控制台为准；真正防止多扣钱靠上面第 8 步的每日上限。

### 谷歌的几条规矩

照 Google Maps Platform 的服务条款和各个 API 的使用政策（2026-11 读的）：

- **不缓存**：谷歌只许长期存地点的编号（place ID），坐标最多存 30 天。二狗干脆都不存：查到的现查现用，不写进硬盘、不进记忆；卡片的预览图也是每次现要，电脑不存（谷歌回的缓存说明照原样交给浏览器）。
- **只画在谷歌地图上**：谷歌的内容不许和别家的地图一起用。谷歌查来的地点、路线只画在谷歌地图上：聊天里的卡片放谷歌的静态地图，点开时地图页这一屏临时用谷歌底图画；谷歌的静态地图里只画二狗交给它的点和线，不和别家的地图拼在一起。
- **署名**：谷歌地图自己在角上印着 Google 标志和版权行，二狗不遮；不在地图上的结果（回答、卡片）写明"数据来自 Google 地图"。
- Key 是你自己的：别给别人用，也别把服务端用的那个发到网上。

不想用了：在「谷歌地图」里点「断开」，两个 Key 从这台电脑上删掉（Google Cloud 里的 Key 还在，不用了去那边删），国外改用 OpenStreetMap。只想不让二狗用谷歌查：关掉「谷歌地图」的「按需查」。也可以在 设置 · 插件 停用「谷歌地图」；移除时勾「连数据删」，会删掉填过的 Key 和记下的用量。

## 让二狗查地点、算路线

直接问二狗就行：

- "从家到公司多久"：开车多久、哪段路堵，坐公交地铁多久、怎么换乘、票价；
- "附近有什么咖啡店""公司旁边有什么吃的""附近的 hawker centre"：按远近列出名字、地址、距离；
- "西溪湿地在哪""去西溪湿地怎么走""我现在在哪"。

**谁来查：** 二狗按地方挑，你不用管。在地图上自己选了某一家（「地图：…」）、二狗又知道你地图上用的是哪家时，它先用那一家查（查到的地点、路线只能画在那一家的地图上）；那一家查不了（比如没填查询用的 Key）就换同一边的下一家，回答里说一句。二狗不知道你地图上选的是谁时（比如语音问的、没开着地图页），照下面的规矩挑。

- **中国大陆里**：填了「Web 服务 Key」用高德——开车带现在的路况，有公交地铁的换乘和票价。
- **国外**（新加坡这类，还有香港、澳门、台湾）：填了谷歌的服务端 Key 用谷歌（有公交、开车带路况，见上一节）；没填用 OpenStreetMap 的免费服务，不用 Key。**没有公交方案、没有实时路况**：开车的用时是按道路限速估的，二狗会给开车和步行；找附近时要说找什么（"咖啡店""hawker centre"），它列不出附近的全部。
- **没填高德的 Key 时，国内也用 OpenStreetMap 查**，二狗会提一句"国内的地点用 OpenStreetMap 查，店名和小路可能不全"。关掉「高德地图」的「按需查」、或者高德说 Key 不对时也一样。

二狗回答时会写明数据来自谁（"数据来自高德"或"数据来自 OpenStreetMap（© OpenStreetMap 贡献者）"）。查到的只是现查现用：不存下来、不进记忆。

**OpenStreetMap 的免费服务有它的规矩**：查地点用的是 Nominatim、算路线用的是 OSRM 演示服务，都是志愿者维护的公共服务，不保证一直能用，每秒最多查 1 次，只适合个人少量地用。二狗照规矩办：一次只查一个、两次之间隔一秒多，带上二狗自己的名字，同样的查询一天之内用存在电脑内存里的那一份（重启就没了，不写进硬盘），不会边打字边帮你联想。用不了时二狗会说"OpenStreetMap 的免费服务暂时不可用"，过一会儿再问就好。

**"家""公司"是哪：** 用你在 设置 · 数据源 · 手机 · 位置 下面「常去的地方」里起的名字。还没起名时二狗会告诉你去哪起名，或者你直接说地址。

**"附近""这里"是哪：** 手机上的二狗 App 最近一次交来的位置（要在 App 里开始记位置）。那个位置是几个小时前的，二狗会提一句"你可能已经不在那儿了"。

**试查一下：** 在「高德地图」里填好 Web 服务 Key 后，点「试查一下」，二狗拿它在北京搜一次「天安门」（固定的词，不是你的位置），列出搜到的几个，看通不通。下面还写着这个月已经查了几次。

**用量：** 高德给个人认证开发者的免费量大约是每月搜地点 5,000 次、地址和路线 15 万次，只免费一年，以高德控制台为准；聊天卡片的高德预览图（静态地图）每张也算一次，和地址、路线算在一起。二狗记着每个月查了几次（只记次数，不记查了什么），快用完时 设置 · 体检 里会提醒。高德说用量到上限、查得太频繁、Key 不对时，二狗如实告诉你；Key 不对的话「高德地图」那一行会写"要授权"，重新填一次就好（填好之前国内先用 OpenStreetMap 查）。OpenStreetMap 不用 Key、不算用量。

## 地图服务能看到你的什么

- **OpenStreetMap**：地图图片由你的电脑替网页去取，OpenStreetMap 看到的是电脑的网络地址和你看的那一片，看不到手机的。取过的图片在电脑上存一阵子，不重复去取。
- **高德地图**：看国内地图时，地图数据由你的浏览器直接从高德取，高德看得到这台设备的网络地址和你正在看的那一片。聊天卡片的高德预览图由电脑去要，高德看到的是电脑的网络地址和那一片。
- **谷歌地图**：看谷歌地图时，地图数据由你的浏览器直接从谷歌取，谷歌看得到这台设备的网络地址和你正在看的那一片；查地点、算路线时电脑只把这一次要的起点、终点或"附近"的那一处发给谷歌。聊天卡片的谷歌预览图由电脑拿服务端 Key 去要，谷歌看到的是电脑的网络地址和那一片。
- **查地点、算路线时**：只在你问的时候，把这一次要的起点、终点或"附近"的那一处发给查的那一家——国内发给高德，国外（和没填高德 Key 时的国内）发给 OpenStreetMap 的公共服务（"家""公司"发的是你起名的那一处的中心，"附近"发的是手机最近交来的那一个点）。找路线另一头的地名时，起点也会一起发过去，让它挑离你近的那个。
- **足迹和二狗画的点、线只在这台设备上画，高德、谷歌只看得到你在看哪一片地图**（2026-11-09 起这样）：足迹由电脑上的二狗现算，算的时候不联网；画出来时——
  - **地图页**：高德、谷歌只出底图。二狗在底图上面盖一层自己的，足迹（轨迹、停留、照片地点）、查到的地点和路线、你现在的位置都画在这一层上，跟着地图一起挪；它们不交给高德、谷歌的程序，那两家只知道地图看的是哪一片（中心、放大到几级）。
  - **谷歌地图关在一个单独的框里**：谷歌的程序在框里跑，读不到二狗的页面（足迹、聊天都在框外面）。**高德地图放不进这样的框**（它取地图要经电脑转一道，框里的请求电脑认不出是你），所以高德的程序和二狗的页面在同一页里跑：二狗不交给它任何点和线，但它的程序技术上读得到这一页。介意的话，在「地图：…」里给国内选 OpenStreetMap。
  - **聊天里的卡片**：预览图是电脑向那一家要的光底图，请求里只有中心、放大到几级、多大、深浅，没有一个点、一条线；点和线由页面自己画在图上面。
  - OpenStreetMap 的地图图片是电脑替网页去取的，足迹由页面自己画，不发给 OpenStreetMap。
  - 地图本身照样要取：你看某一天的足迹，地图挪到那一片，地图服务就知道你在看那一片（和你平时拖地图一样）。
- **点「回到我现在的位置」时**：位置不发给任何地图服务，也不存；圆点和精度圈也画在二狗自己那一层上。但地图会挪到你在的那一片、取那一片的地图，地图服务因此知道你在看哪一片。不想让地图服务知道，在「地图：…」里选 OpenStreetMap 再定位（OpenStreetMap 的图片是电脑替你取的）。

## 用哪几家地图、关掉地图

设置 · 插件里和地图有关的有四个：「地图」（地图页、足迹、聊天里的地图卡片、查地点算路线）和三家地图服务「OpenStreetMap」「高德地图」「谷歌地图」，每家都能单独停用。以前填过的高德、谷歌的 Key、记下的用量、这台设备上「地图：…」选过的都原样认，不用重填、重选。

- **停用某一家**：它不再出现在「地图：…」的列表里，「自动」跳过它；你手动选过它的那一边换回「自动」，说一句。比如停用「高德地图」，国内「自动」就是 OpenStreetMap（谷歌开着的话列表里还能手动选谷歌）；停用「OpenStreetMap」，高德、谷歌都用不了的地方就没有地图可看了。查地点、算路线也只问开着的那几家。
- **三家都停了**（或者开着的那几家都没填 Key）：地图那块空着，写「没有能用的地图，去设置 · 插件里启用一家」，点「去启用」就到设置 · 插件（开着但都用不了时写它们现在都用不了，按钮去设置 · 数据源）；聊天里的地图卡片只有字，没有图。足迹、二狗标的点照样记着，启用一家就画出来。
- **停用「地图」**：三家跟着一起停（它们都要地图插件），地图页、导航里的「地图」没了，聊天里以前的地图卡片显示「地图插件没启用」。再启用「地图」时，跟着它一起停的三家要在设置 · 插件里各自再启用一次；当初就是在设置里停着的「地图」（还没启用过三家），启用它时三家跟着装上。
- **移除并「连数据删」**：「地图」删聊天里的地图卡片；「OpenStreetMap」删电脑上存的地图图片；「高德地图」删填过的 Key 和安全密钥、记下的每月查询次数；「谷歌地图」删两个 Key 和用量。聊天里说到过的地点是聊天记录，不删。

只想不让二狗用高德查：在 设置 · 数据源 · 高德地图 里关掉「按需查」（国内改用 OpenStreetMap 查）。
