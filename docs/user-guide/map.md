# 看地图

二狗里有一张地图：在国内看高德地图，出了国（比如在新加坡）看 OpenStreetMap，看到哪里自动换。你还可以直接问二狗"从家到公司多久""附近有什么咖啡店"，它替你去高德查。以后你去过的地方、聊天里说到的地点、查到的路线都画在这张地图上。

看完这一章你会知道：地图页在哪、怎么让国内的地图更清楚（填高德的 Key）、怎么让二狗查地点和路线、地图服务能看到你的什么。

## 打开地图

**在哪里打开：** 导航里的「地图」。手机上放不下时在「更多」里。

- 拖动挪地图，两个手指捏合（电脑上滚轮）放大缩小，双击放大一级；右上角也有放大、缩小的按钮。
- 左上角写着现在用的是哪种地图：「高德地图」或「OpenStreetMap」。
- 看的地方停下来时自动挑：在中国大陆、填了高德的 Key 用高德地图；国外、香港、澳门、台湾用 OpenStreetMap。
- 下次打开还在你上次看的地方（记在这台设备的浏览器里）。
- 用 OpenStreetMap 时右下角写着「© OpenStreetMap 贡献者」；高德地图自己在角上印着它的标志和审图号。
- 深色外观下地图也是暗的。

## 让国内的地图更清楚：填高德的 Key

没填 Key 时国内也用 OpenStreetMap，地图下面写一句「填了高德 Key 国内地图更清楚」，点「去填」就到填 Key 的地方。

**在哪里填：** 设置 · 数据与设备 · 数据源，点「高德地图」。

1. 在高德开放平台（lbs.amap.com）注册、做个人认证，进控制台建一个应用；
2. 在应用下面添加 Key，服务平台选「Web端(JS API)」。建好以后同一个 Key 下面有一串「安全密钥」；
3. 把 Key 和安全密钥填进「Web 端（JS API）Key」「安全密钥」两个框，点「测试并保存」。二狗拿它们问一次高德（问的是北京天安门这个固定的点，不是你的位置），高德说对了才存下；
4. 「Web 服务 Key」选填：让二狗查地点、算路线时要它（见下一节），在控制台另建一个服务平台是「Web服务」的 Key。

填错了会写原因：Key 不对、安全密钥不对、Key 的服务平台选错了。以前存过的、新填的没通过，照旧用以前的。

Key 和安全密钥只存在这台电脑上。安全密钥不发给网页：高德的地图要它的那些请求，由二狗在电脑上替网页拼上再转给高德。

不想用了：在「高德地图」里点「断开」，Key 和安全密钥从这台电脑上删掉，国内改用 OpenStreetMap。

## 让二狗查地点、算路线

填了「Web 服务 Key」以后，直接问二狗就行：

- "从家到公司多久"：开车多久（高德估的用时）、哪段路堵，坐公交地铁多久、怎么换乘、票价；
- "附近有什么咖啡店""公司旁边有什么吃的"：按远近列出名字、地址、距离；
- "西溪湿地在哪""去西溪湿地怎么走""我现在在哪"。

二狗回答时会写明"数据来自高德"。查到的只是现查现用：不存下来、不进记忆。

**"家""公司"是哪：** 用你在 设置 · 数据源 · 手机 · 位置 下面「常去的地方」里起的名字。还没起名时二狗会告诉你去哪起名，或者你直接说地址。

**"附近""这里"是哪：** 手机上的二狗 App 最近一次交来的位置（要在 App 里开始记位置）。那个位置是几个小时前的，二狗会提一句"你可能已经不在那儿了"。

**试查一下：** 在「高德地图」里填好 Web 服务 Key 后，点「试查一下」，二狗拿它在北京搜一次「天安门」（固定的词，不是你的位置），列出搜到的几个，看通不通。下面还写着这个月已经查了几次。

**用量：** 高德给个人认证开发者的免费量大约是每月搜地点 5,000 次、地址和路线 15 万次，只免费一年，以高德控制台为准。二狗记着每个月查了几次（只记次数，不记查了什么），快用完时 设置 · 体检 里会提醒。高德说用量到上限、查得太频繁、Key 不对时，二狗如实告诉你；Key 不对的话「高德地图」那一行会写"要授权"，重新填一次就好。

现在只能查中国大陆里的地点和路线；国外的查询以后接免费的 OpenStreetMap。

## 地图服务能看到你的什么

- **OpenStreetMap**：地图图片由你的电脑替网页去取，OpenStreetMap 看到的是电脑的网络地址和你看的那一片，看不到手机的。取过的图片在电脑上存一阵子，不重复去取。
- **高德地图**：看国内地图时，地图数据由你的浏览器直接从高德取，高德看得到这台设备的网络地址和你正在看的那一片。
- **查地点、算路线时**：只在你问的时候，把这一次要的起点、终点或"附近"的那一处发给高德（"家""公司"发的是你起名的那一处的中心，"附近"发的是手机最近交来的那一个点）。
- **你每天去过哪里、照片在哪拍的，不发给任何地图服务**：以后画在地图上的足迹只在二狗里画。

## 关掉地图

不想要这个功能：设置 · 插件，停用「地图」。移除时勾「连数据删」，会删掉填过的高德 Key、电脑上存的地图图片和记下的每月查询次数。只想不让二狗查：在「高德地图」里关掉「按需查」。
