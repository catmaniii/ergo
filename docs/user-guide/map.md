# 看地图

二狗里有一张地图：在国内看高德地图，出了国（比如在新加坡）看 OpenStreetMap，看到哪里自动换。你某一天去过哪里、在哪待了多久、照片在哪拍的都能画在这张地图上；跟二狗说"把我今天去过的地方画在地图上"，聊天里就出一张地图卡片。

看完这一章你会知道：地图页在哪、怎么看某一天的足迹、聊天里的地图卡片、怎么让国内的地图更清楚（填高德的 Key）、地图服务能看到你的什么。

## 打开地图

**在哪里打开：** 导航里的「地图」。手机上放不下时在「更多」里。

- 拖动挪地图，两个手指捏合（电脑上滚轮）放大缩小，双击放大一级；右上角也有放大、缩小的按钮。
- 左上角写着现在用的是哪种地图：「高德地图」或「OpenStreetMap」。
- 看的地方停下来时自动挑：在中国大陆、填了高德的 Key 用高德地图；国外、香港、澳门、台湾用 OpenStreetMap。
- **看足迹时一律用 OpenStreetMap**：标题栏右上角的「足迹」开着时，国内也是 OpenStreetMap，也不加载高德的地图程序（见下面「地图服务能看到你的什么」）；关掉「足迹」，国内换回高德地图。
- 下次打开还在你上次看的地方（记在这台设备的浏览器里）。
- 用 OpenStreetMap 时右下角写着「© OpenStreetMap 贡献者」；高德地图自己在角上印着它的标志和审图号。
- 深色外观下地图也是暗的。

## 我的足迹：某一天去过哪

手机上的二狗 App 开始记位置（设置 · 数据源 ·「手机 · 位置」，在 App 里点「开始记位置」）、连上相册以后，地图页能画出某一天的足迹。

- **选哪一天**：标题栏下面那一条，左右箭头是前一天、后一天，中间点开选日期。打开地图时看今天；今天还没有足迹就自动跳到最近有足迹的那一天。某一天什么都没有时写「这一天没有足迹」，旁边的按钮跳到它之前最近有足迹的一天。
- **地图上画的**：
  - 一条线：这一天按时间连起来的位置。在一个地方待着的那一段收成一个点，不画成一团；中间一个半小时以上没记到的地方断开，不把没记到的那段画成直线；
  - 定位针：在哪儿**待过**——一串位置都在 400 米以内、待够 15 分钟算一处（和记忆里每天那条位置摘要同一个算法）。旁边写名字和一共待了多久：起了名的（「家」「公司」）写名字，没起的写手机转出来的地名，都没有的写几点到的。同一处去了几次（早上在家、晚上又回家）只有一个针；
  - 空心小圆点：照片在哪拍的，旁边写几点拍的；挨着拍的（半小时以内、百米以内）合成一个点，写拍了几张。只有时间和地点，**不放照片**；
  - 圆圈：你起了名的常去的地方的范围。这一天没去的那几处圈里写着名字。
- **看详情**：电脑上地图左边列着这一天（每段停留几点到几点、待了多久，不在停留时拍的照片），点一行跳过去，点停留在下面展开详情；手机上点定位针，地图下面出一张卡，点那一条里的「待过 3 个地方……」看这一天的列表。详情里写这一处叫什么、地名、每次几点到几点、一共待了多久、在这里拍了几张照片。没起名的有「去起个名字」，到 设置 · 数据源 ·「手机 · 位置」的「常去的地方」里起。
- **关掉**：标题栏右上角的「足迹」，点一下地图上不画了，再点一下又有（记在这台设备的浏览器里）。
- 聊天里的足迹卡片点开就是这一页，看的是那一天（「足迹」关着也会打开）。

足迹**只在二狗里画，不发给任何地图服务**：是你电脑上的二狗按你手机交来的位置现算的，算的时候不联网。见下面「地图服务能看到你的什么」。

## 聊天里的地图卡片

跟二狗说"把我今天去过的地方画在地图上""昨天去了哪"，它先用一句话说结论（"去了 3 个地方：公司、西湖边、家"），聊天里再出一张**地图卡片**。用语音问也一样：念给你听的是结论，地图在卡片上。

- **足迹卡**：标题写哪一天（"11 月 6 日去过的地方"），下面一块小地图画着那天的轨迹、停留、照片地点，再下面写"待过 3 个地方 · 6 张照片"和去过的几处。小地图不能拖，点它（或右上角「看大地图」）进地图页看那一天。小地图用 OpenStreetMap，和地图页看足迹时一样。
- **查到的地点和路线**：让二狗查"从公司到西湖边怎么走""附近的咖啡店"以后，它可以把结果放成一张卡。高德查来的**只能画在高德的地图上**（高德的规定），所以卡上不画小地图，只写走法（步行、开车……）或查到的几处，写着「数据来自高德地图」；点「在高德地图上看」进地图页，用高德地图画出来。没填高德 Web 端的 Key 时地图页画不出来，会写一句为什么。查到的结果只在电脑上留一会儿、不存（高德不许存），过一阵子再点卡片写"已经过期了"，再问一次就有。
- **二狗标的点、画的路线**：它说"西湖和灵隐寺在这儿"时也会出卡片，画法和足迹卡一样。
- 在地图页看一张卡片时，标题栏下面一条写卡片的标题，点「×」回到足迹。

卡片上只存日期（足迹每次打开现取，手机那边删了卡上也跟着没了）、查询的编号，或者二狗给的那几个点。

## 让国内的地图更清楚：填高德的 Key

没填 Key 时国内也用 OpenStreetMap，地图下面写一句「填了高德 Key 国内地图更清楚」，点「去填」就到填 Key 的地方。

**在哪里填：** 设置 · 数据与设备 · 数据源，点「高德地图」。

1. 在高德开放平台（lbs.amap.com）注册、做个人认证，进控制台建一个应用；
2. 在应用下面添加 Key，服务平台选「Web端(JS API)」。建好以后同一个 Key 下面有一串「安全密钥」；
3. 把 Key 和安全密钥填进「Web 端（JS API）Key」「安全密钥」两个框，点「测试并保存」。二狗拿它们问一次高德（问的是北京天安门这个固定的点，不是你的位置），高德说对了才存下；
4. 「Web 服务 Key」现在可以不填：以后让二狗查地点、算路线时要它，在控制台另建一个服务平台是「Web服务」的 Key。

填错了会写原因：Key 不对、安全密钥不对、Key 的服务平台选错了。以前存过的、新填的没通过，照旧用以前的。

Key 和安全密钥只存在这台电脑上。安全密钥不发给网页：高德的地图要它的那些请求，由二狗在电脑上替网页拼上再转给高德。

不想用了：在「高德地图」里点「断开」，Key 和安全密钥从这台电脑上删掉，国内改用 OpenStreetMap。

## 地图服务能看到你的什么

- **OpenStreetMap**：地图图片由你的电脑替网页去取，OpenStreetMap 看到的是电脑的网络地址和你看的那一片，看不到手机的。取过的图片在电脑上存一阵子，不重复去取。
- **高德地图**：看国内地图时，地图数据由你的浏览器直接从高德取，高德看得到这台设备的网络地址和你正在看的那一片。
- **你每天去过哪里、照片在哪拍的，不发给任何地图服务**：足迹由电脑上的二狗现算，页面只从二狗取，二狗不把这些点发给 OpenStreetMap、高德或者别的地图服务。
  - **看足迹时一律用 OpenStreetMap**：点是页面自己画的，不交给高德的地图程序，也不为它加载高德的程序（聊天里足迹卡上的小地图也是）。高德的地图是页面里运行的高德程序画的，它看得到交给它画的东西，所以足迹不放在它旁边。要是这一页之前已经打开过高德地图（关着「足迹」看过国内、看过高德查来的路线），高德的程序已经在页面里了，打开「足迹」后足迹照样不交给它画；想让它彻底不在，刷新一下页面。
  - 地图本身照样要取：你看某一天的足迹，地图挪到那一片，地图服务就知道你在看那一片（和你平时拖地图一样）。

## 关掉地图

不想要这个功能：设置 · 插件，停用「地图」。停用时聊天里以前的地图卡片显示「地图插件没启用」。移除时勾「连数据删」，会删掉填过的高德 Key、电脑上存的地图图片和聊天里的地图卡片。
