# 视觉风格设计稿

Fable 2026-10-09 画的视觉方案，在设计画布（Design Artifact）上。这里是它们的源文件（`.dc.html`，设计画布的格式），给实现风格的 agent 当参照。
`canvas.json` 是画布的布局；画布上 A 的聊天叫 `Main.dc.html`，拷到这里改名成了 `a-chat.dc.html`。

每套 4 张：聊天（`*-chat`）、任务看板（`*-tasks`）、待我处理（`*-inbox`）、宽屏（`*-wide`，1280 宽）。每张的 `data-props` 里有深色开关 `dark` 和强调色 `accent`，`renderVals()` 里是浅色、深色两套取值。

| 前缀 | 风格 | 要点 | 票 |
|---|---|---|---|
| `a-` | 暖纸手帐 | Noto Serif SC 宋体、米纸底、墨绿印章色、1px 细边卡片、小圆角、圆形字头像 | 40 |
| `b-` | 净白格栅 | Noto Sans SC、黑白细线、一抹信号橙只给"要你"的事、无阴影、细线分隔、密度高 | 39 |
| `c-` | 夜航仪表 | 深色为主、青绿指示色、JetBrains Mono 等宽数字、带点的状态药丸 | 41 |
| `d-` | 软糖圆角 | ZCOOL 快乐体标题、大圆角、浮起的胶囊导航和输入栏、紫罗兰加珊瑚红未读 | 42 |

现有的风格保留为"经典"（39 号票）。
