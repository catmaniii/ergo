# 分诊标签

各个 skill 用五个标准状态来说话。这张表把它们对应到这个仓库实际用的标签名。本地票里，标签写在票文件顶部的 `Status:` 行。

| mattpocock/skills 里的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等提出人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已写清楚，可以交给 agent 独立完成 |
| `ready-for-human` | `ready-for-human` | 需要人来做 |
| `wontfix` | `wontfix` | 不处理 |

skill 提到某个状态时（比如"打上可交给 agent 的标签"），用这张表右列对应的标签名。

想换叫法，改右列即可。
