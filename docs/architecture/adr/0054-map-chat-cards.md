# ADR-0054 聊天里的地图卡片：卡上只存日期和编号，缩略图自己画，高德的结果只画在高德地图上，看足迹一律 OpenStreetMap

状态：已定（431，用户 2026-11-07 定了后两条）

## 背景

- 地图插件有了地图页（ADR-0051）、某一天的足迹（ADR-0052）；查地点、算路线（432，ADR-0053）查到的结果只在地图插件的内存里留一会儿。用户要能说"把我今天去过的地方画在地图上"，聊天里出一张地图，点开看大的。
- 高德开放平台服务协议：3.5 不许存储、缓存服务数据；4.12.4 不许脱离它的服务单独使用或展示；7.7 展示时要标明来源"高德地图"。
- 430 发现：底图是高德时，足迹的点交给页面里运行的高德脚本画，脚本看得到它们。用户 2026-11-07 定：**用户自己的足迹画在 OpenStreetMap 上**（看足迹时不加载高德的网页脚本），守住"每天的轨迹、照片地点不外发"；**高德查来的地点、路线只画在高德的地图上**。
- 聊天页（秘书、任务的会话）上不想加载高德的脚本：它是外站的闭源程序（ADR-0051 唯一的破例），只该在地图页上、要它的时候加载。

## 决定

1. **一种卡片 `map`**（地图插件在数据契约里登记，`map/card.ts`；负载 schema 在协议包 `map-card-schema.ts`）：出来就是已处理，没有动作。卡上**只存画得出来要的最少的那些**：
   - 某一天的足迹：只存日期，网页每次按日期现取（`GET /api/map/day`）。手机那边删了，卡上跟着没了；记忆、彻底删除不用管卡片里的点；
   - 秘书自己给的一组点、一条路线：存坐标（WGS-84）和点旁边的字；
   - 查地点、算路线的结果：只存编号、种类、哪家查的、标题（查的时候起的"从家到公司"），**不存点和线**（高德协议 3.5）。网页按编号现取（新接口 `GET /api/map/drawing?lookup=`，地图插件的服务 `MAP_DRAWING`，`map/drawing.ts`）；内存里没了（两小时、二狗重启）回 404"过期了，再问一次"，卡上只剩标题和这一句。
2. **秘书的工具 `show_on_map`**（`map/show-on-map.ts`，只给秘书）：`date` / `points` / `route` / `lookup` 四选一，`title` 可选。只看（`nature: "look"`、不落任何关注类别），每调一次多一张卡、不算幂等。足迹的工具结果按先后列出待过的几处（名字、几点到几点）、照片张数，叫秘书**先用一句话说结论**，不给坐标（模型那边也是外面的服务）。没写进系统提示：什么时候用、语音时先说结论都写在工具说明和工具结果里。
3. **缩略图自己画**（网页 `plugins/map/MapThumb.tsx`）：用地图页那一套自己写的瓦片地图（`osm-engine.ts`），OpenStreetMap 的瓦片经守护进程转发，点和线自己画；整块 `inert`（不能拖、点不了上面的点，聊天的滚动不被吃掉），点卡片进地图页。聊天页不加载高德的脚本。不用静态图：OpenStreetMap 没有静态图服务，高德的静态图要把点发给高德。
4. **底图只在一处挑**：`plugins/map/scene.ts` 的 `chooseBasemap(中心, 高德能不能用, 画着足迹没有)`。地图页（`MapView.tsx`）和缩略图都经它；缩略图传"高德不能用"（聊天页不加载高德的脚本），挑出来是 OpenStreetMap。**画着足迹时一律 OpenStreetMap**（常量 `AMAP_WITH_FOOTPRINTS = false`）：地图页"足迹"开着（还没取到、这一天空着也算）就不用高德、也不为它加载高德的脚本；关掉"足迹"国内换回高德。要改这条规矩只改这一个值。
5. **高德查来的只画在高德地图上**（`plugins/map/amap-results.ts` 认来源）：卡片上不画缩略图，只写查到的（几处的名字、走法）和"数据来自高德地图"、一个"在高德地图上看"；地图页把它交给 `MapCanvas` 的 `amapScene`，只在底图是高德时画，底图是 OpenStreetMap 时（没填 Web 端 Key、高德没加载上、拖到了国外）不画，写一句为什么。别家查来的（以后 OpenStreetMap，433）照常画缩略图。
6. **点开去哪**：足迹卡去 `#/more/map/<日期>`（430 的地址，"足迹"关着也打开）；别的去 `#/more/map/card/<卡片编号>`（`mapCardPath` / `parseMapCardPath`），地图页从手里的卡片状态取出这张卡画，标题栏下面一条写标题，"×"回到足迹；看卡片时不画足迹。

## 后果

- 卡片几乎不带数据：足迹、查到的结果都按需现取，彻底删除、移除插件时只改写卡片本身（标题、点旁边的字换成删除标记；移除并连数据删时卡片的每个版本整条换成标记）。代价是查到的结果过期以后卡片画不出来，只能再问一次（以后可以按存着的查询条件重查）。
- 聊天里的卡片在工具调用那一刻进会话，排在秘书这一轮回复的文字前面；"先说结论"靠工具结果叫秘书在回复开头说，语音回复念的就是这一句。
- 地图页一打开（"足迹"默认开着）国内也是 OpenStreetMap；要看高德的国内地图得关掉"足迹"。这一页之前已经加载过高德的脚本（关着足迹看过国内、看过高德查来的路线）时，再打开足迹，点照样不交给高德画，但脚本还在页面里（卸不掉），刷新页面才彻底没有。手册照实写了。
- 高德查来的结果在没填 Web 端 Key（只填了 Web 服务 Key）时画不出来，只有文字。
