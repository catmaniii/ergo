# ADR-0051 地图：国内高德 JS API（运行时从外站加载脚本的破例），国外和没填 Key 用自己写的 OpenStreetMap 瓦片地图

状态：已定（429，用户 2026-11-07 定的方向）

## 背景

- 用户要在二狗里看地图（足迹、地点、路线），查地点和路线交给外部地图服务、结果画在二狗的地图上（调研 `.scratch/ergo-v2/research/2026-11-07-maps.md`）。
- 电脑一直走新加坡出口：天地图连不上，高德能连。用户定了：国内底图用高德 JS API（key + 安全密钥，安全密钥不进页面），国外用免费的 OpenStreetMap。
- 项目的规矩是"运行时不请求外部 CDN"（字体也拷进构建产物，`gateway/fonts.ts`）；网页是单个 `index.html`、不缓存、不压缩，库加多少每次打开就多下多少；加 npm 依赖要先说明理由。
- 高德协议：查到的结果"用官方文档列出的功能"展示，不许脱离本服务展示（3.5、4.12.4）；不许缓存、存储（3.5、4.12.3）。OSM 瓦片政策：带能认出应用的 User-Agent、按缓存头缓存（读不到存 7 天）、过期带条件请求、不预取、不离线、右下角署名。
- 坐标：手机报的是 WGS-84；高德是 GCJ-02，大陆里两者差几百米，大陆外一样。

## 决定

1. **一个插件 `map`**：守护进程那一半提供瓦片转发、高德安全密钥代理、`GET /api/map/config`，数据契约里登记数据源 `amap`"高德地图"（填 Key）；网页那一半是地图页 `#/more/map` 和填 Key 那一块。
2. **两种底图，按看的地方自动换**：中心在中国大陆、填了高德 Key（高德没说 Key 不对、脚本加载上了）用高德 JS API 2.0；国外、香港澳门台湾、没填 Key、高德加载不上用 OpenStreetMap。停下来时按新的中心再挑，挑到别的就整个换掉、带着同一个中心和级别。
3. **国外不叠在高德上，用自己写的瓦片地图**（`plugins/map/osm-engine.ts`，几百行，不加依赖）。评估过"只用高德一套、国外在它上面叠 OSM 的自定义瓦片层"（`AMap.TileLayer` 的 `tileUrl` 认 `[z]/[x]/[y]`，大陆外 GCJ-02 等于 WGS-84，对得上），没选，因为：
   - 没填 Key 时高德的脚本根本加载不了，"国内国外都先用 OSM"本来就要一个不靠高德的画法；
   - 高德 2.0 把所有图层画进同一块 WebGL 画布，叠上去的 OSM 瓦片没法单独加深色滤镜（只能靠它没写进文档的 DOM 结构）；
   - 没开"世界地图"高级权限时高德在国外的表现没核实过（这次不许用 key 调高德）。
   也没选 Leaflet：要加依赖；它做的那几样（拖、捏合、滚轮缩放、按需取瓦片、点线圈）自己写够用。以后要矢量底图、离线底图再议。
4. **高德的脚本是二狗唯一一处运行时从外站加载的脚本**（`https://webapi.amap.com/maps?v=2.0&key=…`）：这是对"运行时不请求外部地址"的破例，只在真要画高德地图时才加载（看国外、没填 Key 时一次都不连高德）；演示页和测试换成假的加载器。高德的地图数据由浏览器直接从高德取：看国内地图时高德看得到这台设备的 IP 和正在看的那一片（地图页、填 Key 那一块写明）。
5. **安全密钥不进页面**：照高德官方的代理方式，页面加载脚本前设 `window._AMapSecurityConfig = { serviceHost: <本页来源>/_AMapService }`，高德的脚本把要带安全密钥的请求发到网关的 `/_AMapService/…`，守护进程从密钥区现取安全密钥、拼上 `jscode` 再转（`/v4/map/styles` → webapi.amap.com，`/v3/vectormap` → fmap01.amap.com，别的 → restapi.amap.com），回应原样交回、不缓存、不记查询串。Web 端的 Key 本来就在页面上（高德的设计，能在控制台绑域名）；Web 服务的 Key（432 用）只在守护进程里。页面要的只有 `GET /api/map/config` 给的 Web 端 Key。
6. **OSM 瓦片经守护进程转发**（`/tiles/osm/<z>/<x>/<y>`）：User-Agent 写 `ergo/<版本> (personal assistant; +https://github.com/catmaniii/ergo)`，按缓存头存进数据目录的缓存区（不进备份，总量 256 MB 封顶、超了删最老的），过期带 `If-None-Match` / `If-Modified-Since`，同一张同时只取一次，同时最多 4 个在路上，浏览器断了还在排队的不取，上游不通时有旧的给旧的。不带 Referer：页面是 `no-referrer`，守护进程像本机程序那样去取（政策："Native apps usually do not have a referer, this is ok"）。外网端口和别的地址一样要设备凭证（`<img>`、高德脚本发的请求带着同源的 cookie）。
7. **坐标**：二狗里一律存、传 WGS-84；只在画到高德地图上、交给高德查之前转 GCJ-02（大陆内才转），高德交回来的迭代反算回 WGS-84（`packages/protocol/src/geo.ts`，网页和守护进程共用）。大陆范围是一个粗略的外轮廓，只用来判断该不该转、用哪种底图，不是边界线。
8. **插件读自己数据源的密钥**：加内核服务 `KERNEL.dataSourceSecrets`（`forSource`），地图插件转发高德请求时现取安全密钥；只取自己登记的那个数据源。

## 后果

- 国内地图好看、地点全，高德查到的结果（432）画在高德地图上，合高德协议；国外、没填 Key 照样有地图。
- 页面现在有 CSP 时要放开 `webapi.amap.com` 和高德的数据域名（现在页面本身没有 CSP，这一票没加）。
- Key 被封、高德改接口，国内地图退回 OSM，不报错（页面写一句为什么）。
- 自己写的瓦片地图功能有限（没有惯性、没有动画）；够看足迹、地点、路线，以后不够再换库。
- 数据源 `amap` 不导入；432 加了按需查（查地点、算路线，见 ADR-0053）。
