# ADR-0052 我的足迹：手机插件现算、地图插件开接口，点只在二狗里画

状态：已定（430，用户 2026-11-07 定的隐私规矩）。**451 修订**（[ADR-0059](0059-map-one-current-map.md)）：足迹画在当前地图上，当前地图是高德、谷歌时它们看得到；"只在二狗里画、不发给任何地图服务"只剩"算的时候不联网"

## 背景

- 地图插件（ADR-0051）有了地图页。手机上的二狗 App 交来的位置点、照片的拍摄时间地点、起了名的常去的地方都在"手机"插件自己的存储里（`phone/locations/<日期>.json`、`phone/photos/<日期>.json`、`phone/places.json`），可是没有接口能按天取出来画。
- 用户定了：每天的轨迹、停留、照片地点只在二狗里画，**一律不发给任何地图服务**；只有用户问"附近""从哪到哪"时才把那一两个点发给地图服务（432）。
- 记忆里每天已经有一条位置摘要（"待过 3 个地方……"，`phone/summaries.ts`）：停留按 400 米、15 分钟、一个半小时的空档聚，同一处 500 米以内合起来。地图上画的要和它说的对得上。
- 组合根（`daemon.ts`）不许 import 手机插件的任何文件（`test/phone/boundary.test.ts`），连 `phone/api.ts` 也不行。

## 决定

1. **手机插件算**：`PhoneService.footprints(date)`（`phone/photos-location.ts`，纯函数在 `phone/footprints.ts`）读插件自己那一天的原始点、照片、起了名的地方，交回协议包的 `MapDayView`：精度够的点（按时间）、停留（每段一行，`spot` 相同的是同一处）、有地点的照片（只有编号、时间、坐标，不带地名、不带相册里的地址）、没地点的照片张数、起了名的常去的地方、有足迹的日子（新的在前，最多 400 天）、"位置""照片"连着没有。停留的参数**直接用摘要那一套**（`summaries.ts` 的 `detectStays`、`STAY_RADIUS_M`、`STAY_MIN_MS`、`MAX_GAP_MS`、`SAME_PLACE_M`、`MAX_ACCURACY_M`，只在那里定一次），地图和记忆说的停留是同一回事。
2. **地图插件开接口**：`GET /api/map/day?date=YYYY-MM-DD`，经地图插件的新服务 `MAP_DAY`（`map/api.ts`，实现在 `map/day.ts`）现取手机插件的服务。手机插件是地图插件的**可选依赖**（`wants`）：没装、停用了回"数据源-手机插件没启用"（400），地图照样能看。日期先查写法再读文件（`mapDateProblem`，挡住 `../` 这类）。接口和别的 `/api/` 一样只给本机端口和已配对的设备。
   - 没把接口挂在手机插件上：组合根不能碰手机插件；而且"看某天的足迹"是地图的事，以后别的数据源（导入的轨迹）也可以往里交。
   - 431 的"画在地图上"工具由地图插件登记，同样经 `MAP_DAY`（或者插件里的 `createMapDay`）取，不用另开路子。
3. **页面画**：地图页标题栏下面一条选日期，地图上画轨迹线（停留那一段收成停留的中心，一个半小时没点断开）、停留点（同一处一个点，写名字或系统地名和一共待了多久）、照片小点（半小时内、百米内的合成一个，写几点拍的）、常去的地方的范围圈；宽屏左边列这一天，点停留看详情。都放进 429 的 `MapScene`（编号 `fp-` 开头），两种底图照同一份画，坐标一律 WGS-84（画到高德上时高德那一套转 GCJ-02）。地图页地址 `#/more/map/<日期>` 看那一天（给 431 的卡片点进来用）。
4. **隐私怎么保证**：
   - 守护进程算足迹时不联网（纯函数，地名是 App 在手机上转好交来的）；测试在假内核和主切面里都核了：填了高德 Key，取足迹时假 OpenStreetMap、假高德一个请求都没收到，`fetch`、`http`/`https` 的 `request`/`get`、`net`/`tls` 直连都没被叫；
   - 页面只从本机守护进程取（`GET /api/map/day`），不把点拼进任何地图服务的地址。画在 OpenStreetMap 上时，点是页面自己画的（SVG 和按钮）；画在高德地图上时，点交给页面里运行的高德脚本在这台设备上画（`AMap.Marker`、`Polyline`、`Circle`）——二狗不把它们发给高德，但高德的脚本是高德的程序，它在页面里看得到交给它画的东西；我们没有发现它会把覆盖物传回去，也没法逐行核实（ADR-0051 已经记了这个脚本是唯一的破例）；
   - **底图本身照旧要取**：看某一天的足迹时，地图挪到那一片，取瓦片就会让地图服务知道你在看哪一片（OpenStreetMap 经电脑转发、看到的是电脑的 IP；高德由浏览器直接取）。用户手册照实写了，没写成"地图服务什么都不知道"。

## 后果

- 足迹和记忆里的位置摘要用同一套停留口径；改参数只改 `summaries.ts` 一处，两边一起变。
- 地图插件多了一个可选依赖（手机插件），清单的先后不变（手机在前、地图在后）。
- 每次打开都现算一天（一天最多几百个点），不存算好的结果；起名、改名后马上就是新名字。
- 以后要更强的隐私（比如国内也不让高德的脚本看到点），可以把足迹画在高德地图上面自己的一层里，或者看足迹时只用 OpenStreetMap；这一票没做。**431 做了后一种**（用户 2026-11-07 定）：看足迹时一律 OpenStreetMap、不加载高德的脚本，见 ADR-0054。
