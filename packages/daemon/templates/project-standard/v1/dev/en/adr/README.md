# Decision records (ADR)

> **What goes here**: decisions someone will later ask "why is it like this?" about. One file per decision, numbered in sequence: `0001-<short-name>.md`. Describe the context, the decision and its consequences.
> **When to update**: add one whenever you settle something that's hard to undo (a technology choice, a scope trade-off, a way of working agreed with the user); if you change your mind later, add a new one that says which one it replaces, and keep the old one.
> Project standard v1 · Required (checked): counts as written once this folder holds at least one decision besides this note.

Each record looks like this:

~~~
# <What was decided, in one sentence>

<Context: why this decision was needed>

## Options considered

## Consequences
~~~
