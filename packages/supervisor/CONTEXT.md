# 本地服务管理器 (Local Service Manager)

把这台开发机上各个项目的常驻服务，收敛到一个统一托管、统一监控的地方。
管理器只关心「服务是否活着、要不要重启」，不关心服务内部的业务逻辑。

## Language

**服务 (Service)**：
一个需要长期运行、通常监听端口的进程，是托管的最小单位。
_Avoid_: 后端、应用、进程

**项目 (Project)**：
一个代码仓库，可以包含零到多个服务。my_app 是项目，8799 那个 node 进程是服务。
_Avoid_: 应用、repo、工程

**托管服务 (Managed Service)**：
生死由管理器负责的服务——管理器可以启动、停止、重启它。
_Avoid_: 内部服务、自有服务

**外部服务 (External Service)**：
管理器只探活、不负责生死的服务，例如某个第三方应用自带的本地服务。它挂了管理器只会告诉你，不会去拉。
_Avoid_: 第三方服务、依赖

**钩子 (Hook)**：
由项目提供、管理器在特定时机执行的一条命令。业务语义归项目，执行时机与结果观测归管理器。
_Avoid_: 脚本、启动命令

**注册表 (Registry)**：
管理器持有的、所有服务声明的唯一真理源。
_Avoid_: 配置文件、清单、service.yaml

**纳管 (Onboarding)**：
把一个项目原本自管的服务搬进注册表、并摘掉它自带的自启机制的一次性动作。
_Avoid_: 接入、注册、导入

**重认领 (Re-adoption)**：
管理器启动时，用 PID + 进程启动时间 + 端口监听者三元校验，把上次留下的服务重新认回自己名下的过程。
_Avoid_: 恢复、重连、接管

**孤儿 (Orphan)**：
占着某个已注册服务的端口、但三元校验对不上的进程。管理器不会静默处理它，只会请你裁决。
_Avoid_: 僵尸、野进程

**探活档位 (Probe Tier)**：
一个服务能被观测到的精度，分 process / port / health 三档。档位决定 WebUI 上那盏绿灯到底能保证什么。
_Avoid_: 健康检查级别、监控级别

**漂移 (Drift)**：
注册表里的服务声明与项目现状不一致的状态，是中心化注册表的固有代价。
_Avoid_: 配置过期、不同步

**场景 (Profile)**：
一组会被同时启停的服务，对应你此刻要做的事（做视频 / 打游戏 / 写代码）。
存在的原因是 GPU 是独占资源，「全部启动」在这台机器上是陷阱而不是功能。
_Avoid_: 分组、编排、套餐

**哨兵 (Sentinel)**：
管理器持续运行的两项巡检——端口哨兵发现「在跑但未纳管」的服务，计划任务哨兵发现「会自启但未纳管」的入口。
它只负责让你看见并邀请你纳管，从不阻止你手动启动任何东西。
_Avoid_: 监控、扫描器、守护

**能力 (Capability)**：
一个服务实际支持的操作集（start / stop / restart / health）。管理器只呈现服务真有的能力，
不具备的在 WebUI 上灰显——绝不靠外挂脚本替它伪造一个。
_Avoid_: 功能、支持项

**接入层 (Link Layer)**：
项目嵌入自身代码、用来与管理器对话的统一协议与客户端。接入之后，服务的注册、心跳、
优雅停机回调都由项目自己在进程内实现，不再依赖外部脚本猜测它的内部状态。
_Avoid_: SDK、agent、客户端

**接入 (Linked)**：
一个服务已经通过接入层与管理器建立连接的状态。与「纳管」不同：纳管是账本上的登记与搬迁，
接入是运行期的实时连接。可以纳管但未接入（靠钩子与端口探活），反之不行。
_Avoid_: 连接、注册、在线

**名下的服务 (Owned Service)**：
一个接入的项目经接入层登记、由管理器托管的服务，id 是 `<登记方>--<名字>`，存在注册表的 `services/owned/<登记方>/` 下。
它和手写登记的服务一样是独立的托管服务：登记方只能登记、启停、撤销自己名下的，掉线、重启都不影响它运行。
_Avoid_: 子服务、托管给项目的服务、动态服务

**登记方 (Owner)**：
替名下的服务发登记、启停、撤销请求的那个接入的项目（比如 ergo 的守护进程 `ergo-daemon`）。它只是提出请求的一方，服务的生死仍归管理器（一个服务只能有一个管理者）。
_Avoid_: 父服务、所有者进程、宿主

**忙碌 (Busy)**：
服务自报的「此刻中断会造成损失」的状态，由服务自己定义（正在合成语音、正在跑生图任务）。
它与健康无关：一个忙碌的服务是完全健康的。
_Avoid_: 繁忙、占用中、锁定
