# 二狗记忆系统

Label: wayfinder:map

## Destination

一份可直接进入实现的二狗记忆系统 v1 规格：`.scratch/ergou-memory/spec.md`。

- **覆盖**：素材管理、用户模型的分层与证据、做梦阶段（夜间整理）、记忆在理解指令时的用法。
- **不覆盖**：动机随时间变化的管理（见 Out of scope）。
- **对外接口**：以主地图 [二狗 v2](../ergou-v2/map.md) 的「记忆边界：秘书、任务与记忆管理者之间的接口」为准。

## Notes

- **用户立场**（2026-10-07）：
  - 动机判断不必追求高置信度，"比现状好就是进步"。
  - 做出判断后，要主动形成澄清问题向用户求证。
  - 这些澄清问题就是秘书"意图澄清"的主要来源。
- **形态**：记忆管理是二狗内部一个"运营中"的项目，它的维护者就是记忆管理者。秘书读到的记忆全部由它产出。
- **每个 grilling 票**都调用 `/grilling` 和 `/domain-modeling`，术语写进根目录 `CONTEXT.md`。
- **方法来源**：
  - intent-mining：`docs/research/02-ref-intent-mining.md`，skill 在 `~/.claude/skills/intent-mining`。
  - GUM、Behavior Latticing：`docs/research/05-memory-and-motive-mining.md`。
  - OpenClaw 的记忆写入原则：`docs/research/03-openclaw-and-pi.md` §B2。
- **v1 的素材来源**：与二狗的全部对话、用户的行为信号（对产出的反应、审批决定）、澄清问题的回答、用户主动投喂的材料。被动来源（邮件、日程、文件、浏览记录）以后逐项开启。
- **模型**：先全部用 DeepSeek V4.1 Flash。
- **阶段划分**（用户 2026-10-07，见主地图 Notes）：只有「素材管理」属于第一阶段（2026-10-07 已定），因为二狗从第一天起就要积累素材。其余票标 `Phase: 2`，等主地图第一阶段的骨架规格出来后再做。
- **对外接口已定**（主地图「记忆边界」，2026-10-07）：
  - 记忆管理者是唯一写者；秘书读用户卡、每轮简报和深查。
  - 记忆分短期和长期：短期按时效衰减（半衰期 1 个月，自动检索 3 个月，可调），永不自动删除；长期只被新证据取代。
  - 动机假设只有秘书能看到；任务在用户授权的记忆范围内取用。
  - 用户有两个入口：和记忆管理者的会话（复用维护者会话），以及独立的记忆 Web UI 子模块。
  - 存储遵守主地图的"落盘要有章法"。

## Not yet specified

- **评估**：怎样证明动机层确实有用。思路是：在按时间切分的预测测试，以及"说的≠要的"回放集上，胜过"事实 + 偏好"的基线，同时讨好、过度个性化、泄漏这几项护栏指标不变差。
- **敏感类别**：健康、情绪、财务、关系这几类，哪些允许推断。
- **冷启动**：一开始素材很少时怎么办，例如由用户主动投喂旧材料。
- **两类记忆的边界**：角色经验（属于执行层）和用户记忆（属于记忆管理者）怎么划分。

## Out of scope

- **动机随时间变化的管理**：动机、三观发生变化时，怎样建模、比较新旧、决定取舍。这是用户 2026-10-07 明确记下的**遗留事项**，留待以后单独处理。做梦阶段只负责从新素材里识别"最新的"动机。
- **intent-mining skill 本身的时间维度改进**：独立工作。
