# 记忆的使用与防讨好

Type: grilling
Status: open
Blocked by: 03

## Question

秘书理解新指令时，记忆怎么用？

1. **优先级怎么排**：用户当前的明确指令、用户确认过的偏好、有佐证的动机、尚未证实的假设，这四者冲突时谁说了算？
2. **记忆能改变什么**：只能调整默认值和消歧，还是也能直接改写指令？
3. **怎样防止"更懂你"变成"更会迎合你"**：
   - 讨好；
   - 过度个性化；
   - 把记忆用错场合。
4. **怎样让用户看到依据**：向用户解释时，给出的是具体证据，还是心理诊断？

## Context

- `docs/research/05-memory-and-motive-mining.md` §1–§5：记忆会放大讨好，动机只能用来调整概率和默认值。
- `docs/research/02-ref-intent-mining.md`：深层理解只用于消歧、提问和排序，不能推翻用户的明确指令。
- 「记忆边界」已定：
  - 动机假设只有秘书能看到；用户卡里不放动机假设的原文，只放编译出的交互策略；
  - 计划里要标出引用了哪些记忆，用户可以点开看证据；
  - 记忆简报的条目标明已确认还是假设。
