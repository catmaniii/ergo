# 记忆的使用与防讨好

Type: grilling
Status: open
Phase: 2（暂缓，第一阶段规格之后再做）
Blocked by: 03

## Question

秘书理解新指令时，记忆怎么用？

1. **优先级怎么排**：用户当前的明确指令、用户确认过的偏好、有佐证的动机、尚未证实的假设，这四者冲突时谁说了算？
2. **记忆能改变什么**：只能调整默认值和消歧，还是也能直接改写指令？
3. **怎样防止"更懂你"变成"更会迎合你"**：
   - 讨好；
   - 过度个性化；
   - 把记忆用错场合。
4. **怎样让用户看到依据**：向用户解释时，给出的是具体证据，还是心理诊断？
