# 记忆 Web UI

Type: prototype
Status: open
Blocked by: 02, 03

## Question

记忆 Web UI 是二狗系统里一个独立的子模块，用户在这里查阅和管理自己的记忆。它长什么样、能做什么？需要定下：

1. **能看什么**：短期记忆（素材）、长期记忆、动机假设、"了解你"问题箱，分别怎么呈现；证据链怎么展开。
2. **能做什么**：查看、纠正、删除、回答"了解你"问题、设置记忆规则（如"别推断我的健康"）。
3. **否认一条推断时**：是只停用这条推断，还是连它依据的素材一起删？
4. **调参**：时效半衰期、自动检索窗口、每天顺口问的上限，在这里还是在全局设置里调。

做一个粗原型（可以点击的页面骨架）供评审，原型作为附件链接在本票里。用户的要求是先做出来，逐步迭代。

## Context

- 「记忆边界」（`../../ergou-v2/issues/03-memory-boundary.md` Answer §7）：
  - 记忆 Web UI 调用记忆模块的查看、纠正、删除接口；纠正和删除按"显式记忆命令"处理，确定性地立即生效，受影响的派生内容由记忆管理者随后修订。
  - 它和"找记忆管理者对话"是两个入口：后者复用维护者会话视图，不在本票。
- 主地图「Web UI 信息架构」只给本模块留入口；视觉语言同样继承 AgentSense。
- 本票由地图 Not yet specified 里的"「你眼中的我」界面"升级而来。
