# 用户模型的分层与证据

Type: grilling
Status: open
Phase: 2（暂缓，第一阶段规格之后再做）
Blocked by: 01, 02

## Question

二狗的用户模型分几层？intent-mining 的四层是 L1 表象、L2 情境意图、L3 需求、L4 内核，二狗是否照搬？还需要回答：

1. **每层的记录长什么样**：包括证据、置信度、竞争解释、状态。
2. **门槛放到多低**：按用户的"比现状好就是进步"，形成假设的门槛可以放低。同时要说清楚，假设在什么条件下可以拿来用、在什么条件下必须先问用户。
3. **判断怎样变成问题**：一条判断怎样生成澄清问题。问题要能区分相互竞争的解释，措辞要中性。
4. **用户回答怎样回写**：回答作为证据回写进模型。

- `docs/research/11-user-modeling-systems.md` 给出了一份拼合的命题 schema：
  - 字段：层标签、推理过程、1–10 的保守置信度、适用情境、矛盾关系、强化计数；
  - 修订时追加新版本，不删旧版本；
  - 澄清问题的六个来源：矛盾、低置信但高价值、张力、规范性判断、预测落空、反常输入。
- 「记忆边界」已定（Answer §2）：
  - 记忆分**短期**和**长期**。短期按时效衰减；长期不衰减，只会被新证据取代，旧版本标"已被取代"；动机假设连续预测落空就降级。
  - 本票要定：短期、长期和 L1–L4 各层怎样对应。初步设想是短期 ≈ 表象和情境意图，长期 ≈ 稳定事实、需求、内核，以及由它们编译出的交互策略。
  - 记忆简报的每个条目要标明短期还是长期、已确认还是假设；短期条目注明是几天前的。不显示成低置信度。
  - 按类型设不同衰减速度，v1 不做。
