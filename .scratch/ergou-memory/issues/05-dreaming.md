# 做梦阶段：夜间整理的流程与产出

Type: grilling
Status: open
Phase: 2（暂缓，第一阶段规格之后再做）
Blocked by: 03, 04

## Question

做梦阶段每晚要定下这几件事：

1. **何时、跑什么**：几点触发；复盘哪些素材；按什么步骤跑（去重、抽取、更新模型、生成问题、产出给秘书的记忆）。
2. **一致性**：如何保证只有一个写者。
3. **出错与成本**：失败了怎么回退；token 预算多少；能否放在 DeepSeek 的空闲时段跑。

## Context

- 用户在立项 grilling Q20 中说：晚上整理白天用户说的话，复盘一遍，识别用户最新的动机，类似其他 agent 的做梦阶段。
- `docs/research/03-openclaw-and-pi.md` §B2.3：OpenClaw Dreaming 的 Light、REM、Deep 三个阶段，以及两道关。
- 时间维度不在本票范围内，见地图的 Out of scope。
- `docs/research/11-user-modeling-systems.md`：
  - Honcho 的触发条件：新增 50 条、冷却 8 小时、空闲 60 分钟，有新消息就取消；阈值只计 L1。
  - 建议的步骤顺序：更新与矛盾 → 带证据修订 → 按张力分组（最多 3 层）→ 预测记分 → 生成问题。
- 「记忆边界」已定：
  - 做梦阶段是内置"记忆管理"项目的定时作业，记忆管理者是唯一写者。
  - 产出：从短期记忆提炼长期记忆（每条带证据链接指回短期记忆）、刷新用户卡（每天最多一次）、生成"了解你"问题。
  - 记忆管理者没有对外有副作用的工具，也不能派任务。
