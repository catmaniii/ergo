# 二狗宣传视频脚本 v7（= v6 + 下面的修改）

2026-10-14，用户看了 v6 预览，提了三点：

1. 开场"误解用户意图"的例子不太合适，换成用户给的这个：
   > 用户只说："周五晚上又要跟他们吃饭了。"
   >
   > 普通 Assistant 只能理解为一个日程相关的陈述。长期记忆 Agent 如果知道：
   > - "他们"是用户的某个业务合作团队；
   > - 最近三次聚餐之后，用户都表示很累；
   > - 用户并不是不喜欢这个团队，而是不喜欢聚餐中的应酬；
   > - 用户本周正在准备一个重要项目；
   > - 用户曾经明确表示，想减少低价值社交，但不希望影响合作关系，
   >
   > 它就可能理解：用户是在表达对这次聚餐的犹豫，而不只是通知一个日程。更好的回应可能是："又是上次那个合作团队吗？如果这次也只是普通聚餐，可以考虑礼貌地缩短参加时间，不一定需要全程留下。"
   >
   > 注意，这仍然是一种有证据的意图假设，而不是 Agent 已经准确读懂用户内心。设计目标应该是：高置信度时主动理解和行动，低置信度时表达合理猜测，只在确有必要时澄清。不应该为了减少提问，就让 Agent 擅自覆盖用户当前的明确意愿。
2. 开场里回话的那个助理不是二狗，换一个女声。
3. 结尾二狗有了对用户的记忆、提取出深层意图、理解正确时，回应用户的那句话用二狗的声音。

其余照 v6（`video-script-v6.md`）。

- 如果第六幕的时间不够，主动建议卡可以再压，第六幕整体最多往后多占 2 秒，片尾跟着顺延。
