# 二狗宣传视频脚本 v4（重新设计，草稿待和用户对）

2026-10-13 用户对卖点的讲法（大意整理）：

1. **懂你的记忆只该在你电脑上。** 云端的个人助理也能帮你收邮件、整理东西，但它不了解你，邮件也是在云上处理的。对你的深度理解、长期记忆里的关键数据（偏好、身份信息、隐私）只该存在本地。有人会问"你不还是调用 DeepSeek 吗"：长期记忆的全量不在别人那里，每次只发一点点信息给模型，比把全部记忆、偏好、身份、隐私都放到云上好得多。
2. **不混，而不只是不忘。** 用户的真实痛点：让 OpenClaw 今天做项目 A、明天做项目 B，到后面就乱了。二狗的秘书只负责传话、理解需求，自己不做事；做事的是专门的 agent，各有独立的上下文、工具、skill。
3. **按项目组织 agent。** 有的做法按 agent 群组来组织，比较费 token。二狗按项目组织：每个项目一个主 agent（维护者），能拆的任务它会分给子 agent，但子 agent 只干活、没什么存在感。要详细聊一个项目，就找这个项目的维护者。
4. **未来最重要的是对用户深度需求的理解。**
   - 理解用户意图是公认的最大难点；安全成立的前提，也是对用户需求的精准理解。
   - 传统记忆系统只记表面一层。可人很复杂：不同场景下表现不同，还会口是心非。看起来矛盾、甚至相反的表象背后，有他的深层需求和动机。
   - 挖到这一层，用户再说一件事，你不光能准确理解意图，还能判断他当前的情绪、是不是在说气话。
   - 这需要掌握用户尽量全的数据，包括他在各种情况下的反应——所以本地记忆系统很重要。
5. **信任是攒出来的。** 足够懂你的 agent，加上长程任务执行中足够的保障，人才能放心把工作交给它。在这个基础上它才能主动提出用户真正需要的事；主动提得靠谱的次数多了，人对 agent 的信任慢慢积累起来。这就是安全感：**安全感不是天生的，是靠争取的**。"把事情交给我，你只管拍板"只是其中一个卖点，要综合起来想一句新的宣传语。

## 一句话

**主宣传语：越懂你，越放心。**

| 候选 | 好处 | 不足 |
|---|---|---|
| **越懂你，越放心。**（推荐） | "越……越……"本身就是"一点点攒起来"；"懂你"连着本地记忆和深度理解，"放心"连着专人专项、长活保障和信任 | 偏抽象，要靠片子把"懂"和"放心"演实 |
| 安全感，是一件件攒出来的。 | 最贴用户说的"安全感靠争取" | 只讲了结果，没点出"懂你" |
| 懂你的，留在你身边。 | 一句话把"懂你"和"本地"连上 | 没有"放心交事"那一层 |

用法：
- 片名卡、片尾大字都用"越懂你，越放心"。
- "安全感，是一件件攒出来的"当第四幕的旁白。
- 片尾二狗说："懂你的，留在你身边；交给我的，一件件办好。"
- "你只管拍板"降为第三幕里的一句台词。

## 全片的论证线

**要真懂你，就得知道很多 → 这么多关于你的东西，只该放在你自己电脑上 → 交给它的事，要专人专项、不会乱 → 长活要有保障、回来一眼看懂 → 一件件做到位，信任慢慢攒起来 → 更懂你之后，它能主动替你想到（二期）。**

每个论点都走同一个三拍：**痛点画面 → 二狗的真实界面 → 看得见的证据**（打开的文件夹、一个数字、一次被拦下的操作）。

## 说话要照实（写片子时守住）

- **邮件**：二狗现在不接邮件（外部连接器在规格的以后再做里）。第一幕的邮件对比只做原理动画，不演"二狗现在帮你整理邮件"。按你的需求整理邮件放进二期"更懂你"那段演。
- **"在你允许的情况下才发"**：现在是"发给你选的模型，每次只发这一轮用得上的"；"敏感信息外发前先问你"是即将推出。片子里不能说成现在每次外发都问你。
- **每个专人配独立的模型**：现在每个项目、任务的工具包能单独配 skill、外部工具、能力开关，提示词也能单独改；单独配模型目前只有秘书能改。片子里先说"独立的上下文、工具、skill"。要说"独立的模型"，得先做一张小票。
- **"按 agent 群组组织更费 token"**：只讲"不开会、不互相转述"的道理，不报没测过的数字。
- **信任进度条**：是比喻性的动画，二狗里没有这个功能。
