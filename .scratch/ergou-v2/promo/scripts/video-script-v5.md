# 二狗宣传视频脚本 v5

2026-10-14。在 v4 的基础上，加了用户补充的一个重要理念，并把它做成"即将推出"里的重头戏：

> 用二狗开发的项目，**第一**，天生作为 MCP 接入二狗，二狗可以用语音操控它；**第二**，这个应用转运营上线以后，作为一个传统的 UI 界面，可以在很多个点天然集成二狗的语音交互。任何键盘、鼠标交互的地方，按下一个键就能说话。
>
> 比如：
> - 鼠标在输入框里，说"帮我把我去年那个什么什么的附件加进来"；
> - 接入一个外部浏览器，访问外部网站要上传照片时，说"把我周末在杭州拍的照片贴上来"，不用自己去找。
>
> 现在还没有这样的例子，可以做个界面出来演示；这个功能是待推出。

v4 定下的照旧：
- 宣传语"越懂你，越放心"。
- 声音：二狗用灿灿的远；你用设计 A，30 岁男声；旁白用设计 C，知性女声；换声音示例用设计 A，20 岁女声。
- 配乐 B 版 `music-v4-B.mp3`。
- 画面：玻璃光纹界面、天空蓝白背景、银白外框、白字深色描边。
- 第三幕的真实项目卡。
- v4 里"说话要照实"那一节，见 `video-script-v4.md`，本版继续守。

## 新卖点放在哪、怎么串

它和"懂你的记忆在本地"是一条线上的：
- "去年那份发票""周末在杭州拍的照片"，二狗之所以找得到，**是因为你的东西和对你的了解都在你自己电脑上**。
- 所以新的一幕放在"信任攒出来"之后、"更懂你"之前。
- 主题是：**你做的每个应用，都长着二狗的耳朵**。

## 论证线

要真懂你就得知道很多 → 这些只该放在你电脑上 → 专人专项、不会乱 → 长活有保障、回来一眼看懂 → 一件件做到位，信任攒起来 → （即将推出）你做的应用天生会说话，哪里能点鼠标，哪里就能说话 → （即将推出）更懂你，替你想到。

## 第五幕的两个演示界面怎么做

- 都是**专门为片子做的演示网页**，不接二狗、不真的发邮件、不连外部网站。写成静态 HTML，用 Playwright 按脚本操作并录屏。按键提示、附件飞入、照片飞入都是页面里的动画。
- **写邮件窗口**：看着像通用的办公软件，收件人、主题、正文、附件栏都有。不仿任何真实产品的样子和名字。正文可以写一封普通的报销邮件，收件人是虚构的"财务"。
- **外部网站**：虚构一个相册分享站，名字也虚构，不像任何真实网站。浏览器外框画成通用的样子，地址栏写一个明显虚构的域名，比如 `photos.example.com`。
- **照片**：插画风或程序画的风景，内容是西湖、断桥、茶园，不用真实照片，也不用网上下载的图。
- **快捷键**：统一用"按住 右 Alt 说话"，画面里有一个键帽动画。
- **文件名、日期**：全是虚构的，不用用户的真实文件。
