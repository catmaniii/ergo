# 二狗宣传视频脚本 v2

2026-10-13 用户看了 v1 的预览后说：没有突出最大的卖点——**你的记忆和关键数据都存在你自己电脑上**；要把更多二狗的特点加进来，每一类功能都要覆盖。

v1（`video-script-v1.md`）里定了的照旧：给开发者和 AI 圈看、横屏 16:9、全片用户不打字只说话、不点名别家产品、不用真人出镜（触点动画、银白设备外框）、界面用玻璃光纹、背景天空蓝白、白字带深色描边、二期用简单动画加"即将推出"角标、声音分工（用户和旁白：蒋欣；二狗：灿灿的远）、片尾二狗说"把事情交给我，你只管拍板。"

## 用户 2026-10-13 定的

- **对比的说法**：不写哪家厂商，对比的是"云端 AI 助理把记忆存在云上，二狗存在你自己电脑上"。不说"其他个人 agent 都在云上"——OpenClaw 这类自托管的 agent 记忆也在本机，开发者会挑这个错。
- **配乐**：照 B 版的风格在 Suno 重新生成一首和新长度一样长的（方案 c）。
- **功能点**：用户让我从每一类里挑一批，下面"功能覆盖"一节是挑的结果。
- **用户想加的两样还不存在**："身份证、护照这类证件资料存在本地"和"敏感数据发给大模型前先找你确认"二狗现在都没有；长期记忆的提炼是第二期。片子里先照实说现在有的，这两样放进"即将推出"（待用户确认）。

## 说"本地"时的分寸（必须照实说）

| 说法 | 依据 |
|---|---|
| 对话、你说过的每句话的原话副本和索引、项目档案、任务记录、附件、花费账本都存在你电脑上 | 守护进程跑在本机，数据目录、SQLite 都在本机；个人数据不进仓库 |
| 语音识别、语音合成都在本机显卡上跑 | faster-whisper large-v3 本机 GPU；本机 audio.cpp 合成 |
| 手机、平板经你自己的通道连回你的电脑；新设备要你批准，随时能收回 | 配对批准、可吊销 |
| 密钥区 agent 读不到 | 三条硬底线之一 |
| **要模型思考时，会把这一轮用得上的内容发给你选的模型服务（现在是 DeepSeek）** | 推理在云端，不能说成"全程离线" |

不能说"全部离线""数据永不出电脑"；要说"**存**在你电脑上"，以及"只有要动脑的时候，才把这一轮用得上的内容发给你选的模型"。
