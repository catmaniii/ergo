# 二狗宣传视频脚本 v3（按场景组织，草稿待和用户对）

2026-10-13 用户对 v2、v3 初稿的意见：
- 要把**全量卖点**按场景归类，**通过几个场景把这些功能全部展示一遍**。
- 语音不算很有特色，"声音不出门"弱化，只讲**声音可以自定义**。
- 断电恢复本身不吸引人。改成讲它背后更要紧的一点：**计划、授权和规矩由系统记着，不靠 agent 的记性，做多久都不走样；重启了从断的地方接着做**。
- 用户用 OpenClaw 时真实遇到的问题：**在同一个上下文里让它做多个项目，到后面就忘了**。二狗的做法是每个任务一个 agent，项目有维护者，项目里的子任务各有子 agent 负责，它们之间能通信，能被秘书控制，也向秘书汇报进展。这一条升格成独立的一场，放在"本地"之后。

照旧的：
- 给开发者和 AI 圈看，横屏 16:9。
- 用户不打字只说话。
- 不点名别家产品，痛点画面用不带品牌的界面。
- 不用真人出镜：触点动画，银白设备外框。
- 界面玻璃光纹，背景天空蓝白，白字带深色描边。
- 二期用简单动画加"即将推出"角标。
- 声音分工：用户和旁白用蒋欣，二狗用灿灿的远。
- 片尾二狗说"把事情交给我，你只管拍板。"。
- 对比只说"云端 AI 助理把记忆存在云上"。说"本地"照 v2 的分寸表：存在你电脑上，要动脑时只把这一轮用得上的内容发给你选的模型，不说"全部离线"。
