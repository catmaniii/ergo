# 89 — 主导航上秘书那一项固定写"秘书"，秘书页左上角写"个人秘书：<名字>"

Status: done
Blocked by: 无
Spec: [第一阶段规格](../spec.md) 第 19 节"名称"；43 号票（个人助理的名字）、33 号票（主导航）

## What to build

用户 2026-10-11 提："tab 中秘书那一项的标题改成秘书，页面左上角写个人秘书：二狗（二狗可以换成其它设置的秘书姓名）"。改成：

- **主导航上那一项固定写"秘书"**：宽屏左侧竖栏、竖屏底部横栏都一样，和任务、项目这些项一样是普通的两个字，不再显示用户起的名字或"助理"，也不带名字的底色标签。设置里风格预览那排导航图标跟着变。
- **秘书页标题栏左上角写"个人秘书：<名字>"**：名字是设置里起的那个（照旧带名字的底色标签，改名后跟着变）。宽屏下标题下面的"主线会话"照旧。名字很长时在末尾截成省略号，不能挤掉右边的活动状态、发起任务、▤ 按钮。
- 默认名字（"个人助理"）、设置里起名的地方、输入框的"和<名字>说…"、界面别处提到名字的地方都不动。
- 11 套视觉风格都要看一遍：导航上的"秘书"和别的项一致；标题里"个人秘书："和名字标签排在一起好看。水墨国风的标题名字是放大的朱砂印章（用户定），前面多了"个人秘书："以后 360 宽的手机上要放得下（印章该缩就缩，或者截省略号，照风格说明里的思路定）。
- 只为导航上那一项显示名字而写的东西（名字缩成两个字的函数、各风格里导航上名字标签的样式）不再用了，删掉。

- [x] 秘书页标题是"个人秘书：<名字>"，改名后跟着变；有测试。
