# 119 — 经典风格换实心导航图标、主色可选 8 种

Status: done
Blocked by: 无
Spec: [第一阶段规格](../spec.md) 第 19 节（界面）；39 号票（视觉风格）

## What to build

用户 2026-10-13 原话："默认界面下所有的那个选项，那个 tab 的图标都是那种 unicode，感觉和其他风格有点不一致，能不能把它改掉？这样让设计语言一致一些"；"默认界面的那个亮色要支持可设置，现在只有蓝色嘛，最好就是你选择默认界面之后那个配色主要的亮色有蓝色以外，还有比如说橙色……给个 6~8 个选项，比如说红色，绿色什么之类的"。用户选了**实心图标**和 **8 色**。

1. **经典风格的导航图标换成实心图标**：现在 `ui/main-nav.tsx` 的 `ENTRIES` 用表情符号（💬📋📦🔔📅📊🧠⚙️⋯），别的风格在各自的 style.css 里按 `data-nav` 用 mask-image 换成自己的图标。经典也照这个路子：一套统一画法的**实心剪影图标**（自己画的 SVG，不加依赖），覆盖导航的所有项（秘书、任务、项目、待办、日历、消耗、记忆、设置、更多），未选中用次要字色、选中用主色；浅色、深色都清楚；红点、数字角标位置不变。设置里风格预览（`StylePreview`）的那排图标跟着变。别的风格不动。
2. **经典风格的主色可选 8 种**：蓝（现在的默认，值不变）、靛紫、青绿、绿、橙、红、粉、石墨灰。
   - 在 设置 · 外观 · 风格 里，选中"经典"时下面出现一排色块（"主色"），点了立即生效，当前那个打勾；选别的风格时这排不显示（别的风格不受影响）。
   - 换色后凡是用主色的地方都跟着变：按钮实色块、链接、选中项、导航高亮、开关、进度等（`primary`、`primary-fill`、`nav-on` 以及从它们派生的 token）。每种颜色都有浅色、深色两个值：主色当字用时在对应底色上清楚，主色块上的白字对比度 ≥ 4.5:1（照 classic/style.ts 里 `primary-fill` 注释的做法）。
   - 和风格一样存在本机（照风格选择现在的存法），刷新、重开都保持；首屏不闪（风格是 index.html 的内联脚本先挂上的，主色也一样）。
   - 鸿蒙 App 里一样能用（同一个页面）。

## Acceptance criteria

- [x] 经典风格导航不再有表情符号，所有项是同一套实心图标；选中、未选中、红点、角标在浅色和深色下都清楚；别的 10 套风格的导航不变
- [x] 设置 · 外观 · 风格 选经典时出现 8 个主色色块，点了整页立即换色、刷新后保持、首屏不闪；选别的风格时不显示、不影响
- [x] 8 种颜色浅、深两套值，主色块上的白字对比度 ≥ 4.5:1（有测试算对比度）
- [x] 默认（没选过）仍是现在的蓝色，现有用户看到的不变
- [x] 相关测试、typecheck、oxlint 通过；截图：经典浅色、深色下导航（选中不同项）和 8 种主色各一张拼图，给主会话看

## Comments

- 2026-10-13 做法：图标照别的风格新建 `classic/style.css`，按 `data-nav` 用 mask 换成自己画的 24×24 实心 SVG（表情字号 0 藏起来，图标框 22×22，角标的 CSS 不动）；主色做成风格清单里通用的 `accents`（现在只有经典），选了的挂根元素 `data-accent`（内联脚本先挂、`app/theme.ts` 接手，localStorage `ergou-accent`，蓝就是没这个键），生成的样式表只在 `[data-style="classic"][data-accent=…]` 上换 `primary`、`primary-fill`、`user-bubble`（`nav-on` 跟着 `primary`）；色块在设置里紧跟经典那一行下面，经典的预览按选的主色画。和票不一样的：你发的消息气泡 `user-bubble` 也跟着主色换（票只点了 primary / primary-fill / nav-on，浅色下气泡本来就是同一个蓝），"跟你有关的" `you`、内容类型色 `c-user`、数据小签这类带含义的颜色不换；设置列表副标题换过主色时写"经典（橙）"；"更多"页菜单里的表情符号没换（别的风格也没换）。
- 2026-10-13 合并：压缩合并进 main，没有冲突，按规矩没重跑测试（实现时相关 16 个文件 1276 条、typecheck、oxlint 都过）；`build:web` 部署。和票不一样的几处（自己发的消息气泡跟主色、带含义的颜色不换、"更多"菜单里的表情没换）照实现者的说法保留。
