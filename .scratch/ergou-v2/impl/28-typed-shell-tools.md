Spec: [第一阶段规格](../spec.md) 第 9 节（守卫）、第 21 节（实现细节补充）、第 3 节（agent 子进程与 pi 封装层）、第 11 节（项目与维护者）、第 17 节（被杀后的恢复）

## What to build

维护者干开发类的活时，常用的 bash 操作不再走通用 bash，而是调用带类型的工具：git 状态和差异（只读）、git 提交、git 推送、建远端仓库、git 合并、跑测试、在工作目录里装依赖、启动构建。每个工具的参数是结构化的（仓库路径、分支、提交说明、远端、仓库名和可见性等），在 Git Bash 里、以工作目录（或建在工作目录里的 worktree）为当前目录执行，结果以结构化的形式交回模型。类型事先定好，守卫不用拆命令就知道它落在哪些关注类别里，时序规则也能直接套用；时间线上它们不带"通用 bash"标记。

每个工具在工具注册表里登记类别标签、"做完告诉我"标记和"只读或幂等"标记（登记表见 Notes）：git 提交、合并、装依赖做完告诉我；推送、建远端仓库落入"以我的名义对外发送或发布"，任务里要计划里列了才做；其余直接做、只记录。它们和 v1 时序规则模板配合：push 之前必须跑过测试，删除或覆盖工作目录里的文件之前必须已提交，force push 一律禁止。带类型的工具和通用 bash 里的同一操作规范化成同一种形式，绕到通用 bash 去做也一样受约束。

演示：faux provider 剧本里，一个任务的维护者在工作目录（一个临时 git 仓库）里改完代码，先看状态和差异，再提交（时间线上标"做完告诉我"）；没跑测试就推送，被拦下，说明里写着要先跑测试；跑测试通过后再推送，按计划里的授权项放行；试一次 force push，一律被拦下。

## Acceptance criteria

- [ ] 守卫切面（表格测试）：八个工具按 Notes 里的登记表登记类别标签、"做完告诉我"和"只读或幂等"标记，注册表内容可断言。判定：状态和差异、跑测试、启动构建为直接做只记录；提交、合并、装依赖为做完告诉我；推送、建远端仓库落入"以我的名义对外发送或发布"——对话里先问我，任务里有覆盖它的授权项（对象范围含这个远端或仓库名）就放行并标授权内，没有就先问。这些判定都不带"通用 bash"标记。
- [ ] 主切面（临时 git 仓库作工作目录，faux 剧本）：维护者依次调用状态和差异、提交、跑测试、启动构建、合并，工具在 Git Bash 里、以工作目录为当前目录执行，返回结构化结果（状态和差异列出改动的文件和差异；提交返回提交号；跑测试和启动构建返回退出码和输出摘要）；聊天里的工具调用 part 带工具名、参数摘要和判定，不标通用 bash；执行成功的调用按 05 号票的规范化参数追加进效果日志，效果摘要记下提交号、涉及的文件、测试是否通过。
- [ ] 主切面：跑测试、启动构建、装依赖以退出码判成败，退出码非零算执行失败，不进效果日志；单次调用超时（默认 10 分钟，这三个工具可以声明更长，可配置）被中止，同样算执行失败。工具起的进程在 Job 对象里，环境里没有任何密钥（测试脚本里查环境变量看不到）。
- [ ] 守卫切面（场景文件）+ 主切面：没跑过测试就推送 → 拦下，说明写明"push 之前必须跑过测试"；测试没通过（不进效果日志）后推送 → 仍拦下；测试通过后推送 → 按处置放行。带 force 的推送（含 `--force-with-lease` 这类等价写法）一律禁止。工作目录里有未提交改动的文件，删除或覆盖前被拦下，提交之后放行。同样的序列换成通用 bash 的 `git push`、`git push --force`，判定一致。
- [ ] 主切面：合并把指定分支（比如 20 号票子 agent 在 worktree 里的分支）合并进工作目录的当前分支；有冲突时中止合并，工作目录回到合并前的状态，冲突文件列在给模型的结果里，这次调用算执行失败、不进效果日志。
- [ ] 守卫切面：工具的仓库路径参数按 03 号票的参数规则过路径围栏——工作目录（含建在里面的 worktree）之内照常判定，工作目录之外落入"越出项目目录"，落在受保护区域（配置区、密钥区、数据库区、二狗程序目录）的一律"永不"。跑测试、启动构建、装依赖不接受任意命令：执行的是工作目录里已有的项目约定（比如 package.json 里的脚本），模型只能传附加参数；装依赖只装进工作目录，不接受全局安装。
- [ ] 主切面：这些工具随工具包的 bash 开关一起出现在会话里，bash 关着时一个都没有；秘书的固定工具里没有它们。推送、建远端仓库、装依赖要联网：工具包的联网开关关着时直接拒绝，说明里写明要开联网；开着时按上面的类别判定。推送和建远端仓库的对外一侧在测试里换成可替换的执行器，不真的连网。
- [ ] 前端状态层回放：提交、合并、装依赖在时间线上按"做完告诉我"的样式出现，推送按授权内或问过的样式出现，都不带"通用 bash"标记（样式本身归 25 号票；25 若尚未完成，先断言 part 字段）。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。
