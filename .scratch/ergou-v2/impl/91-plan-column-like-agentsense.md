## What to build

用户 2026-10-11："任务详情里面，左边有计划预览的界面，那个分界线要可以拖动。另外项目的多个阶段有可能是并行的。这部分请你完全参考AgentSense最新版本。参考那边的计划阶段的展示风格，包括计划阶段的展示部分不显示阶段的详情。需要的时候点击阶段的卡片，最右边详情里面会展示这个阶段的详情。不需要在左边阶段图示下方展示了。总之，这部分完全参照AgentSense的长程任务来做。"

主会话认出的 AgentSense 方案（以它的代码为准，照搬，不简化；有偏离先问）：

1. **左栏画成依赖图**：数据用阶段的前置依赖和阶段组（二狗的数据模型已经能表示）。阶段号 = 最长前置链的长度，同号就是并行，详情里再分 4a、4b（`milestone/check.ts:78,97`）。自上而下分层、同层并排、曲线连线（`milestone.tsx:62-160`）。卡片只有"第 N 阶段 + 状态图标 + 标题"，执行后加情况小图标（防 / 拦 / 拉 / 问，带 ✓），等授权时标敏 / 权 / 外 / 问的个数（`milestone.tsx:167,1939`）。状态靠边框：没开始虚线、在做蓝框呼吸、完成绿底、没通过红框、不做的淡化划掉（`look.css:84`）。栏底的情况计数照旧。
   - 界面上别处写"第 N 阶段"的地方（阶段标签、聊天、待办、详情）跟着用依赖层的号；守护进程写进文字里的阶段号要和界面一致，查清楚哪些是顺序号，改不了的先问主会话。
2. **点阶段卡片 = 选中 + 在最右边的详情栏打开这一阶段的详情**（84 号票的阶段详情内容不变）；左栏下面那块阶段卡片删掉。再点同一张卡详情不关，详情栏 ‹ 一层层退回（`drawer.tsx:191`）。计划还没批准时点卡片进计划详情并定位到那一阶段。
3. **计划还没批准、计划调整中也画在左栏**，标"新 / 改"，去掉的画虚线。
4. **左栏和聊天之间的分界线能左右拖**：默认 320，最窄 200，最宽屏宽的 60%（`App.tsx:411,695`；`layout.css:4295`）。栏顶 × 整栏藏、标题栏左边的阶段标签再打开（88 号票）照旧。
5. **手机抽屉**：半开是横向阶段条（并行的叠在同一列），全开是整张依赖图加计数，都不放阶段卡片；点卡片整页滑入详情（`drawer.tsx:197`）。
6. **聊天按阶段成框**（长程任务的会话；`stageBox.tsx:15,127`）：聊天里只留你说的、Agent 说的、计划和把关记录，其余每个阶段收成一个框；框上两行：阶段、标题、情况、状态；下面一句结果；点开是要点和这一阶段的每次操作，底部"验收和规则 ›"进详情。联动：点左边卡片不动聊天；聊天滚动时标题栏的阶段标签跟着变；点聊天里计划提纲的一项，左边图上那一阶段高亮（`App.tsx:707`）；详情里"回到会话里这一段"定位聊天。和二狗已有的工具调用组（52）、缩放和书脊（54、55）怎么合，照 AgentSense 的思路定，冲突的地方先问主会话。
7. **并行的阶段执行照旧一次一个**（AgentSense 也是），图上只画并排。
