# 80 — 彻底删除补登记三类事件的改写函数：计划的决定、提问卡的回答、授权续期的决定

Status: done
Blocked by: None — can start immediately
Spec: [第一阶段规格](../spec.md) 第 15 节彻底删除；ADR-0008；21 号票

## What to build

66 号票做的时候发现：`plan_decided`（计划的决定）、`questions_answered`（提问卡的回答）、`grant_renewal_decided`（授权续期的决定）这三类事件会产生素材，但没有登记彻底删除的改写函数（`PurgeRewriters`）。用户在记忆删除卡上彻底删除这类素材时，"没登记改写函数的事件类型被点到时整个彻底删除被拒"，删不掉。

照 ADR-0008 字段级改写的口径给三类事件登记改写函数：只把带用户原话的文本字段（打回的意见、回答的文字、续期时写的说明）换成 `PURGED_TEXT`，id、状态、决定原样保留，派生视图重放后结论不变。

## Acceptance criteria

- [x] 三类事件产生的素材都能在记忆删除卡上彻底删除；删除后原话取不到，计划、提问卡、授权的状态和决定不变；主切面测试。
- [x] 所有测试通过（vitest），lint（oxlint）无报错。

## Comments

- 2026-10-10 实现（在 worktree 分支上，待合并）：
  - **改写函数**（`tasks/material-sources.ts`，`daemon.ts` 里登记）：
    - `plan_decided`（`planDecisionPurge`）：只换 `note`（计划卡打回的意见、计划变更卡和流程计划卡上拒绝时写的话、"让维护者改"的说明）；决定、计划、版本、卡片、勾掉和收窄的授权、有效期原样。计划卡、计划变更卡、流程计划卡上处理结果里的这段话由已有的卡片改写换掉（素材记着卡片 id）。
    - `questions_answered`（`clarificationAnswerPurge`）：每题的 `answer` 换成删除标记（自己写的、选现成选项的都换）；题号、问题、推荐、按没按推荐、是不是现成选项原样。提问卡类型加了 `purge`，卡上记的答案一起换。
    - `grant_renewal_decided`（`grantRenewalPurge`）：**票面写的"续期时写的说明"不存在**——续期事项上只有"续期""不续"两个按钮（`inboxAction` 只带 `choice`），事件里没有用户写的话；授权项的说法是维护者写的、任务名是任务的，决定和有效期是结构。登记成原样不改，素材照忘掉删除。
  - **连带交给 agent 的那条通知**（同 ADR-0008 里审批的"挂起之后才拒绝时递给 agent 的那条通知"；不连带的话秘书会话、维护者会话里还原样看得到）：提问卡的回答交回秘书或提问的维护者、计划卡打回和流程计划卡拒绝/"让维护者改"交回维护者的通知，按卡上动作的幂等键加 `#notice` 找；计划变更卡上拒绝的通知（`execution.ts` 的 `notify`，幂等键是随机的）按同一事务里跟在决定后面、属于这个任务、原样引着「这段话」的第一条找（旧数据也找得到）。找到的整条换成"已删除"，所在会话追加 `messages_purged`，秘书、维护者据此改写会话文件。没写话的决定不连带。
  - **没改写、写进 `PURGE_LIMITS` 的**：确认计划时在卡上改的假设栏、加的关注类别——它们已经是确认的计划（`plan_decided` 的 `plan`、计划卡负载、`task_plans`）的一部分，维护者照它做、守卫照类别的规则判，改了就改坏了状态。`PURGE_LIMITS`（设置页、记忆删除卡上的说明）加了这一句，ADR-0008 后果、`docs/dev.md` 同步。项目的任务被打回时意见转进重新起草的工单，照旧属于"工单内容里转述的话"。
  - **事件日志例外**：还是"彻底删除"这一个（`appendBatch` 的 `purge`），没有新开口子。删除项目时随项目删内部任务的素材（66 号票）照旧靠 `skip`，连带出来的通知在维护者会话里，已经整条换成了标记。
  - **测试**：主切面 `test/main/memory-delete-decisions.test.ts`——提问卡的回答和计划卡打回的意见在记忆删除卡上一起彻底删除（整个事件日志、卡片、交回秘书和维护者的通知、两边的会话文件里都没有原话；提问卡已处理、计划已拒绝，重建派生视图后不变）；计划变更卡上拒绝写的话走设置里按时间段删除（通知按引用找到、别的通知不动，这版计划还是已拒绝）；授权续期的决定在记忆删除卡上彻底删除（素材删掉，事件原样，续期后的有效期不变，重建后不变）。变基到最新 main 后全量通过，oxlint、类型检查无报错。
