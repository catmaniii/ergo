# 88 — 宽屏下任务看板全屏、点卡片全屏进任务；长程任务的阶段面板能收起

Status: ready-for-agent
Blocked by: 无（60、84 已合并）
Spec: [第一阶段规格](../spec.md) 第 19 节（Web UI）；60 号票（三种做法的任务界面）、55 号票（阶段抽屉、书脊）、56 号票（详情页）

## What to build

用户 2026-10-11 提：宽屏下左边是任务卡片列表，右边还有长程任务的阶段，然后才是聊天区，太窄；阶段面板也收不起来。改成：

- **任务看板在宽屏下默认全屏**：整个内容区都是看板，每个任务一张卡，按现有分组（等我、进行中、运营中、最近结束、已归档）排成多列网格（列数随宽度自适应，卡片宽度有个合适的下限），一眼看清有多少任务、各是什么状态。卡片内容沿用现在的看板卡（种类、状态、进度、token、活动……），不新增信息。
- **点任务卡片 → 全屏显示这个任务**：看板换成任务详情（会话、计划、工具包、消耗等页签照旧），左上角有返回看板的按钮；浏览器后退、鸿蒙返回键也回到看板。回到看板时保持原来的滚动位置。从别处跳进任务（待我处理、聊天里卡片的"去看任务 ▸"、通知）直接打开全屏的任务详情。运营中的提醒 / 定时作业卡同样点开全屏。
- **任务详情的宽屏布局**：长程任务时左边是阶段面板，中间是聊天区；打开"详情 ›"时右边照旧出详情栏（56 号票），可关。
- **阶段面板能收起**：面板上有收起按钮，收起后只留一条窄边（显示第几阶段 / 进度），点一下再展开；默认展开，这台设备记住收起还是展开。窄屏（手机）照旧用阶段抽屉，不变。
- 只改任务看板；项目页、待我处理的宽屏布局不在本票（用户没提，要的话另开票）。
- 所有视觉风格都要看一遍：卡片网格、返回按钮、阶段面板收起后的窄边在 11 套风格（经典 + 10 套方案）下都正常；水墨国风、复古杂志的看板是一行一行的样子（用户定的），在多列网格里也要排得好看。

## Acceptance criteria

- [ ] 宽屏打开任务看板：全屏多列卡片网格，分组照旧；有测试（前端状态 / 回放），截图 1280、1600 宽。
- [ ] 点卡片进全屏任务详情，返回按钮、浏览器后退回到看板并保持滚动位置；从待我处理、聊天里的卡片跳进任务直接全屏；有测试。
- [ ] 长程任务的阶段面板能收起 / 展开，记住选择；收起后聊天区变宽；有测试。
- [ ] 窄屏（390、360）行为不变；有测试或截图核对。
- [ ] 11 套风格下宽屏看板、任务详情（阶段面板展开 / 收起）截图核对，浅色深色。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。
