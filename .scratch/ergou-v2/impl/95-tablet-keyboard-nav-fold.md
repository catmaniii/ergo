# 95 — 平板上点输入框页面就"刷新"、没法编辑（系统提示等设置页）

Status: done
Blocked by: 无（小改动，轻流程，主会话直接改）
Spec: 33 号票（主导航按空间自适应）、71 号票（系统提示）

## What to build

用户 2026-10-12 在平板（横屏，宽屏布局）上：系统提示的编辑框一点进去页面就刷新，再点又刷新，没法编辑；手机上没问题。

原因（hilog 核实：每点一次，网页高度 1644 → 888 → 50 毫秒后回 1644）：输入法弹出让网页矮了一半，左侧竖栏放不下全部导航项，"设置"收进"更多"；设置收没收起，MorePage 画的是两种结构（SettingsSection / 更多菜单 + ListDetail），编辑框被换掉、失去焦点，输入法收回，页面变高，设置又放出来——来回一趟就是"刷新"。

改法：正在往输入框里打字时导航只放出不收起（状态层 `nextNavFit`），输入框失去焦点后按最近一次量的结果重算。

## Acceptance criteria

- [x] 打着字时窗口变矮，导航不收起、编辑框不被换掉、焦点还在；有状态层测试（`nav.test.ts`），无头 Chrome 把 1148×730 压到 1148×395 核过。
- [x] 失去焦点后照常收起；有测试。
- [x] web 相关测试、typecheck、oxlint 通过。
