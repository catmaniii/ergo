# 122 — 界面里不再用 Unicode 字符当图标

Status: done
Blocked by: 无
Spec: [第一阶段规格](../spec.md) 第 19 节（界面）；39 号票（视觉风格）、119 号票（经典风格实心导航图标）

## What to build

**范围（用户 2026-10-14 随后收窄）**：

> 只改那个那些 tab 选项界面上的东西，如果是文本框、项目阶段进展、聊天文字框用来标记的那些 unicode 不换。

- **要换的**：导航 tab、"更多"页菜单条目、设置这类选项列表、输入栏的键盘、语音、附件按钮，以及 ⚙ 🔔 💬 ▤ 这类按钮。
- **不换的**：文本框、阶段进展、聊天和时间线文字里的标记，state 里拼成句子的说法，还有 ▾ ▸ ▴ 展开收起、语音气泡的 ▶ ❚。
- 下面原来写的排查范围，以这一条为准。

用户 2026-10-14 原话：

> 标准界面里面键盘和语音输入的图标还是用 unicode，还有设置里面的记忆，就其他里面的记忆和设置按钮也还是 unicode。你帮我排查一下，看看所有 11 套界面里面还有没有用 unicode 的，如果有的话，把 unicode 去掉……目前 11 套那种线条性的图标倒都是一致的，目前先保持一致吧。

**排查**：在 11 套风格下，逐个页面、逐个组件找出所有拿表情符号或 Unicode 符号当图标的地方，有一处算一处。
- 典型的：
  - 输入栏的 🎤 ⌨ 📎 📄 🖼 📥；
  - "更多"页菜单的 📅 📊 🧠 ⚙️；
  - ⚙ 设置按钮、🔔 提醒铃铛；
  - 💬 ▤ 这类视图切换；
  - 语音气泡的 ▶ ❚；
  - ▾ ▸ ▴ 展开收起；
  - ✓ ✕ ✗ 勾叉；
  - ○ ◐ ◑ ◔ ⏹ 进度和状态；
  - ⚠ ⛔ 🔒 ⏰ 🔁 🔍 👤 ✋ ❓ ✅ ✉️ 📨 💭 这类状态标记；
  - ↩ ↺ ↓ ↑ 这类单独当按钮或标记用的箭头。
- 主会话粗扫过一遍源码，`packages/web/src` 里非注释的这类字符有五十来种、两百多处，**以实际界面为准**。
- 有的风格已经用 CSS 把某些位置换成了自己的图标，比如各风格按 `data-nav` 换导航图标、经典的实心导航图标，这些地方在那套风格下不算。

**替换**：
1. **统一用线条图标**。照现有那几套风格的线条图标来画：
   - 24×24 视框，线宽约 1.75，圆头圆角，颜色用 `currentColor`；
   - 自己画 SVG，**不加依赖**；
   - 放在一处共用，比如 `ui/icons.tsx`。
   风格要换某个图标的，照现有的机制在自己的 style.css 里覆盖。
2. **"更多"页菜单里和导航同一项的条目**（日历、消耗、记忆、设置……），用和导航同一个图标，跟着每套风格走：
   - 经典用 119 号票的实心图标；
   - 其他风格用各自的导航图标。
   做法：同一套 `data-nav` 机制，或者抽成共用的。
3. **经典风格的导航**仍是 119 号票的实心图标，不改。其余位置统一用线条图标。
4. **哪些不算**：
   - **写在句子里的符号**是排版，可以留，比如"A → B""第 2/3 条""·"；
   - 时间线、详情里**由文字拼出来的说法**（state 里拼的句子）如果带着表情符号，比如 `⛔ 拦下`、`📨 来信`：在界面上要么换成图标组件，要么去掉符号只留文字。
   - 拿不准的列出来给主会话。
5. 无障碍：
   - 图标都 `aria-hidden`，按钮照旧有文字或 `aria-label`；
   - 原来靠符号表达状态的，比如 ✓ 已完成，换成图标后状态的文字说明不能丢。
6. 鸿蒙 App 里一样，同一个页面。
