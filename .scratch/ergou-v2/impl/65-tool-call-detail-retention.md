# 65 — 工具调用完整内容的总量上限和保留期

Status: ready-for-agent
Blocked by: None — can start immediately
Spec: [第一阶段规格](../spec.md) 第 19 节"会话区照搬 AgentSense"的详情页；53 号票 Comments"存储的总量上限和保留期以后单开票"

## What to build

53 号票起，每次工具调用的完整参数和返回（单个值最多 200KB）都另存一份，供详情页（56 号票）现取。现在没有总量上限，也不过期，日子久了会一直涨。

- 给这份完整内容定**保留期**和**总量上限**，超出的按时间从旧到新清掉。
- 清掉的只是完整内容：工具调用记录、要点、效果记录、时间线照旧。详情页取不到时照 53 号票 404 的样子用摘要顶着，并注明"完整内容已过保留期"。
- 还被用着的不清：未结束的任务和流程里的调用、还在待办里的卡片引用到的调用。
- 清理在守护进程里定时跑，不挡启动；清了多少写一行日志。设置里显示现在占了多大。

## 用户定的（2026-10-09）

1. 保留多久？建议 **90 天**。
2. 总量上限多大？建议 **2 GB**，到了就从最旧的清。
3. 要不要在设置里给一个"现在就清理"的按钮？建议给，点之前确认。

- [ ] 所有测试通过（vitest），lint（oxlint）无报错。
