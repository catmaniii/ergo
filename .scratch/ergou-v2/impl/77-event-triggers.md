# 77 — 事件触发：二狗内部事件、本机文件夹变化；流程步骤能引用事件里的值

Status: done
Blocked by: 76
Spec: ADR 0025（任务分两个维度）

## What to build

用户 2026-10-10 定：条件触发**靠事件推送**（ADR 0025）。本票在 76 号票的触发底座上接事件来源。

- **事件来源登记表**：每个来源登记名字、能产生哪些事件、事件带哪些字段、可以按什么过滤。以后接邮件、webhook 等只加一项，本票不接。第一批接两个来源：
  - **二狗内部事件**：任务或流程完成、失败、转"等我"；项目状态变化（筹备中 → 建设中 → 使用中 → 停用）；定时任务的一次运行失败。可以按具体某个任务、项目过滤。
  - **本机文件夹变化**：指定文件夹（可含子文件夹）里新增、修改、删除文件，可以按文件名模式过滤（比如 `*.pdf`）。同一个文件短时间内连续变化的，合成一次。守护进程重启后接着监视；停机期间的变化，启动时比对一次补发。**不许监视**二狗的数据目录、密钥区、受保护区域。
- **事件交给谁**：一次运行收到触发它的那一批事件（76 号票的排队合并），作为结构化的输入交给 agent。
- **流程步骤引用事件**（用户定）：
  - 步骤的参数可以写成占位，比如"事件.文件路径"；计划卡上照这样显示；
  - 执行时代入这次事件的值，59 号票的核对按代入后的值比；
  - 一批里有多个事件时，流程对每个事件各走一遍步骤。
- **简单提醒也能挂事件**：事件发生时发一条通知，不用 agent。
- **界面**：
  - 发起对话框的"什么时候做"多一个"事件发生时"：选来源、选事件、填过滤条件；
  - 看板卡上显示"在等什么事件"、最近一次触发；
  - 任务详情里每次运行写明是哪一批事件触发的。

## Acceptance criteria

- [x] 监视一个临时文件夹，放进一个匹配的文件，普通任务被触发，agent 拿到文件路径；主切面测试。
- [x] 某个任务完成时触发另一个普通任务；有测试。
- [x] 流程的步骤参数引用事件路径，执行时代入，核对按代入后的值；放进两个文件时流程各走一遍。
- [x] 连续快速变化合成一次；运行中又来事件，排队合并；有测试。
- [x] 不能监视数据目录、密钥区、受保护区域，有测试。
- [x] 简单提醒挂事件，事件发生时发通知。
- [x] 所有测试通过（vitest），lint（oxlint）无报错。

## Notes

- 文件监视用 Node 自带的能力，或者照规格不另装依赖；如果要装新依赖，先停下回报（装依赖要用户点头）。
- 测试用临时目录，不监视真实的用户目录。
