# 50 — 视觉风格"水墨国风"

Status: ready-for-agent
Blocked by: 39（视觉风格的底座和"净白格栅"）, 43（个人助理的名字）
Spec: [第一阶段规格](../spec.md) 第 19 节（Web UI）"外观"

## What to build

在 39 号票搭好的风格底座上，加一套风格"水墨国风"，内部 id 是 `ink`。设计稿是 `docs/design/styles/` 里方案 I 那一行（`i-chat`、`i-tasks`、`i-inbox`、`i-wide`），说明见同目录的 README。

要点：宣纸底、马善政书法标题（只用在标题上）、朱砂印章样式的名字标签、虚线细格、无阴影。

设计稿里画了个人助理名字的底色标签（43 号票），这套风格要覆盖名字标签的 token，画成设计稿里的样子。

## Acceptance criteria

- [ ] 设置 · 外观 · 风格里多出"水墨国风"，选了立即生效，按设备记住（沿用 39 号票）。
- [ ] 按设计稿还原四个画面：聊天（文字气泡、语音气泡、审批卡、输入栏、名字标签）、任务看板、待我处理、宽屏，浅色、深色都要。其余页面按同一套 token 和规则推出来。
- [ ] 设计稿里出现了产品没有的信息或控件，不加，写进 Comments。
- [ ] 字体按 39 号票的办法由二狗自己提供，只在选了这套风格时加载；字体许可证写进 Comments。
- [ ] 39 号票的对比度测试覆盖这一套，浅色、深色都达标。
- [ ] 只动这套风格自己的文件和风格清单里的一行。如果必须改共享代码，写进 Comments 并说明原因。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。
