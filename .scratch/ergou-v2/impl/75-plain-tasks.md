# 75 — 普通任务：有任务卡、自己的 agent，后台跑 agent loop；助理可以自己交出去

Status: ready-for-agent
Blocked by: 70（对话审批开关、给 agent 配齐工具）
Spec: [第一阶段规格](../spec.md) 第 8 节；ADR 0025（任务分两个维度）、ADR 0019、ADR 0023

## What to build

用户 2026-10-10 定：任务的"做法"多一种**普通任务**（ADR 0025）。

- **是什么**：有任务卡、有自己的 agent，在后台用 agent loop 直接做；**不规划、不授权、不检查**。守卫按"普通对话"那一套走，受 70 号票的开关管，默认直接做；受保护区域、密钥的硬拒绝照旧。
- **谁发起**：
  - 用户在发起对话框里选"普通任务"；
  - **助理可以自己决定交出去**：用户在对话里交代一件要花时间的事（比如"去搜一下这首歌，把音频下下来"），助理建一个普通任务在后台跑，在对话里告诉用户一声"已交给后台去做，做完告诉你"，不必等用户点明。流程和长程任务照旧要用户点明。
- **执行**：一个专门的 agent（和维护者同一套装配：工具、skill、联网，照 70、72 号票给维护者的那套）。任务书就是用户或助理交代的那段话，加上必要的上下文。
- **项目**：只涉及一个项目的，照 64 号票建成这个项目的内部任务，由项目维护者做；不涉及项目或涉及多个项目的，上全局看板，有自己的 agent。
- **做完**：agent 结束这一轮就自动算完成，给用户一句结果；助理在对话里转告。用户在任务详情里接着说话，它接着做，任务重新变成进行中。归档照旧由用户手动。
- **界面**：
  - 看板上有卡，标"普通任务"；
  - 任务详情没有计划、阶段那些栏，只有会话（54 号票的缩放会话）和工具调用详情；
  - 发起对话框的"做法"多一个"普通任务"，排在最前面、默认选中。"什么时候做"留给 76 号票。

## Acceptance criteria

- [ ] 用户从对话框发起普通任务，agent 在后台做完，任务自动完成，助理转告结果；主切面测试。
- [ ] 助理自己交出去：有一个工具（比如 `delegate_task`），不需要用户点明；工具说明写清什么时候该交（要花时间、要联网下载、要跑很多步），什么时候自己在对话里做就行。
- [ ] 用户在完成的普通任务里接着说话，任务回到进行中，接着做；有测试。
- [ ] 只涉及一个项目的建成内部任务，有测试。
- [ ] 普通任务里"先问我"类的操作不弹审批卡（开关关着时），硬拒绝照旧；有测试。
- [ ] CONTEXT.md、规格第 8 节按 ADR 0025 改写。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。

## Notes

- 任务的种类字段（流程、长程任务）加一种 `plain`；协议包、看板分组、任务详情的栏位都要认它。
- 测试里 LLM 用假的。
