# 66 — 删除项目时补齐清理：秘书和跨项目评审读过的项目内容

Status: done
Blocked by: 64（项目内部任务：同样改删除项目的流程）
Spec: [第一阶段规格](../spec.md) 删除项目、彻底删除的口径（21、32 号票）；53 号票 Comments"还剩的口子"

## What to build

删除项目时，二狗会把这个项目留下的内容一起改写掉（ADR-0008 的字段级改写）。53、56 号票之后还剩两个口子，项目删了，它的内容还留在别处：

1. **秘书读过的项目档案**：秘书能读项目档案，它读过的全文在秘书会话的工具调用里（含 53 号票另存的完整内容），这些调用没有项目归属，删除项目时不改写。
2. **跨项目任务的评审**：涉及多个项目的任务，评审子 agent 会读各项目的档案和工作目录；任务不属于单个项目，删除其中一个项目时这些读取不改写。

要做的：删除项目时，按"读的是不是这个项目的东西"（路径落在项目的档案目录或工作目录里，按真实路径判断）找出这两类调用，把读到的内容照彻底删除的口径改写掉；调用本身、工具名、结局留着。
