# 87 — 发了语音气泡就不再显示"调用了 1 个工具"，工具调用放进气泡的"详情"

Status: ready-for-agent
Blocked by: 86（send_voice）
Spec: [第一阶段规格](../spec.md) 第 22 节"用户打字时也能发语音"；56 号票（详情入口）、57 号票（工具调用折成一行）

## What to build

用户 2026-10-11 实测 86 号票后提：agent 用 `send_voice` 发出语音气泡后，聊天里还多一行"调用了 1 个工具"，重复了。改成：

- **发出了气泡的 `send_voice` 调用不在聊天里单独显示**：会话层的"调用了 N 个工具"不算它（这一轮只有它时整行不出）；缩放各档逐个画调用的地方也不画它。只认"这次调用确实发出了气泡"（合成好或只发出一部分）；没发出去（服务没开、忙、太长、没有参考音色……）的照常显示这一行，和会话里的失败说明一起让用户看得到出了什么事。
- **气泡的"详情 ›"里能看到这次工具调用**：语音气泡长按 / 右键菜单里本来就有"详情 ›"（56 号票）；打开后的详情里加上这次 `send_voice` 调用的记录（和工具调用详情同样的内容：说成人话的那句、参数、守卫怎么判的、用了多久、结果），工具发的语音才有，语音回复（用户发语音那一轮）的照旧。
- 合成还在进行时（气泡没出来前）怎么显示，照现在"正在回复…"的规矩，不额外闪出那一行再消失。

## Acceptance criteria

- [ ] 打字这一轮 agent 发语音成功：聊天里只有气泡，没有"调用了 1 个工具"；同一轮还调了别的工具时，那一行只算别的；有测试（前端回放）。
- [ ] 发语音失败：那一行照常显示；有测试。
- [ ] 缩放各档不单独画发出了气泡的 `send_voice`；有测试。
- [ ] 气泡的"详情 ›"里能看到这次工具调用的记录；有测试；截图 390、1280，两种风格。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。
