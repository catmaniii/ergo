- **执行中也能"从这里重做"**：AgentSense 只要阶段开始过就能重开，执行中也行；二狗现在只对做完的任务能返工。照 AgentSense：维护者正在做就先停掉这一轮（暂停用的那个办法），这一阶段和依赖它的后续阶段回到未开始、交付件和验收结果清掉，原会话末尾追加一条重开记录，旧记录在界面上标已废弃，再让维护者接着做。会话**不分支**（"撤回到这里"那种会话树退回在 85 号票）。"谁能改"表跟着加行。

**这一轮改了什么**

1. **"谁能改"表**（`protocol/task-transitions.ts`）：条件 `reopenable` 去掉，从某个阶段重做统一要 `not_converted`（建好了阶段的长程任务，没转为项目、不是流程）；执行中、已暂停、排队中原地 `rework`，已完成、等我（哪种原因都行，中断不确定也行）、失败的 `→ running / queued`。哪个阶段开始过由控制器、任务详情再看。做不了时的说法：没建阶段的"任务还没开始执行，没有能重做的阶段"，转为项目的"不能再从某个阶段重做"。
2. **先停稳再重置**（照 AgentSense `runtime.ts`：generation++ → abort + waitForIdle → reopen）：`task_action` 的 `rework` 走 `actRework`，先查能不能做（做不了马上拒绝），再 `stopTurn`——`AgentSession.stopTurn` 拦住会话不再开始下一条输入、中止手头这一轮、等它真的结束（最多 10 秒），停稳后按此刻的任务重置、提交，最后放开会话去处理重做的通知；网关的 `taskAction` 支持晚一点才有的结果。到点还没停下的那一轮作废：之后它的调用守卫一律拦下（`blockedBy: "superseded"`，"这一轮已作废"），不执行，也就不算进任何一轮。效果日志记下判定那一刻任务的重做次数（`Task.reworks` → `EffectRecord.reworkNo`），阶段记下第几次重做时重开的（`TaskStage.reopenNo`，替掉第一轮的 `reopenedAt`）：重做之前判定、结束得晚的不算新一轮"已经做了的事"。
3. **作废卡着的东西**（用户定）：重开范围里的阶段在等的通知（等你验收、卡住求助、超预算、交给我做）和这几个阶段的审批卡；任务还没确认的计划变更卡（提议记 `decision: "voided"`、`by: "system"`，这版计划不再生效，不进素材、不换多项目的工单；在等它的范围外阶段回到未开始）；整个任务的卡住求助、中断不确定（等你确认它时）、失败后的抉择（失败的任务）。通知记成处理过（"已作废"），卡过期；再点旧按钮回"已经重做过，这一条作废了 / 这张卡作废了"（`handledNote` / `Card.expiredNote`，卡上的处理结果也写这句）。批准旧审批卡不再有"可以重试"。从待我处理里验收还要是阶段此刻在等的那一条（`awaitingUser` 核 `waitingOn`）。
4. **名额满时重做**：`resume` 回到排队中时照样记成 `rework`（带你点的阶段、重开了哪几个），看板、尝试记录收得到；交给维护者的那句写"执行名额满了，先排队"，暂停着的写"任务暂停着：用户继续之后再做"。
5. **验收途中重做的竞态**：`completeStage` 验收结束时阶段的 `attempts` 和这次提交的不一样就作废（重开后又交的是新的一次）。
6. **之前的尝试记录**（照 AgentSense）：重做的通知加"之前那一次的尝试记录开始阶段时会给你"；重开时记下它最近一次没通过的标准（`TaskStage.lastFailed`），开始阶段的交代带上"这个阶段之前交过 N 次，最近一次没通过的标准：…"（没有的写"（无）"）。
7. **ADR 0010**：删除项目时 `purgedTask` 连阶段的 `summary`、`lastFailed` 一起换成删除标记。
8. **彻底删除**：`outputReactionPurge.related` 带出来的卡片版本（结论卡上你写的说明）进 `refreshed`，和别的卡一样追加改写后的新版本，开着的页面换掉；`conversation/purge.ts` 的注释改了（连带改写时间线记录的还有用户对产出的反应）。

**和评审意见、AgentSense 不一样或需要说明的（回报主会话，没勾"先回报"那项）**

1. 作废的范围：审批卡只作废重开范围里的阶段的（范围外阶段的审批跟这次重做无关，批准后维护者照常收到"可以重试"），交给我做也只作废范围里的；计划变更卡一律作废（提议是整个任务的，按之前那一轮提的）。
2. 授权已用几次照旧累计：重做之前那一轮用掉的不退还（不撤回就不退，和 AgentSense 不撤回时一样）；"不算进新一轮"落在"这一轮已经做了的事"上（按判定时的重做次数分轮）和守卫拦下作废那一轮之后的调用上。
3. 到点没停下（10 秒）的那条路没有主切面测试：faux 模型的回合一中止就结束，做不出停不下的回合；主切面验的是顺序（这一轮结束的事件在重做事件之前落盘，请求 8 秒内回）、作废之后的效果按轮分（单元测试里重做之前判定、结束得晚的不列）。
4. 违反了怎么办合成一份后，检测项全览从"违反后直接拦下 / 按规则退回 / 当场确认"、阶段详情从第一轮的"违反就拦下 / 违反时问你"都换成计划卡的说法；AgentSense 检测项全览写"违反后直接拦截"。
5. "问"换成计划卡的停点后说法跟计划卡一样（"第 N 阶段「X」由你验收""第 N 阶段「X」：工具 · 范围（落在「先问我」类别里……）"），多了收窄的那几条。
6. 范围外已验收阶段复验不做（85 号票）。
