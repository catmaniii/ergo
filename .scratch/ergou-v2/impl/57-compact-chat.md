# 57 — 聊天区精简：工具调用合成一行，有详情的都带 ›

Status: ready-for-agent
Blocked by: 52（会话条目层）, 56（详情页）
Spec: [第一阶段规格](../spec.md) 第 19 节"会话区照搬 AgentSense"的聊天区精简；调研 `docs/research/15-agentsense-zoom-detail-task-modes.md` §3、§5.3、§6.1 的 T6、§6.2 第 7 条

## What to build

用户的要求：

- 聊天界面里显示的东西要尽量切中要害。
- 工具调用不要每一步、每个参数都列出来，归到一条里。这一条不是聊天气泡，而是高度很小的一行字，右边一个 ›，暗示能点开。点开后，右边的详情页再看调了哪些工具、什么参数、返回了什么。
- 有详情的气泡要有展开按钮，让人知道能展开。

## Acceptance criteria

- [ ] **工具调用组**：一轮里两段话之间连续的、顺利执行的工具调用，显示成一行小字"调用了 N 个工具 ›"。
  - 不是气泡，高度很小。
  - 命中关注类别的加小签，比如"· 1 次做完告诉你"。
  - 点开进详情页（56 号票）。
- [ ] **出问题的调用也在框里**（用户 2026-10-09 改）：被拦下、问过你、你拒绝了、出错、等你批准的调用不单独成横条，放在同一个"调用了 N 个工具 ›"的框里、按先后排；那一行加小签标出出了什么问题（比如"· 1 次被拦下""· 1 次出错"），颜色比顺利的组醒目；点开在详情里看是哪一次。审批卡本身照旧单独一张（要用户点）。
- [ ] **连续的同类调用合成一条**（用户 2026-10-09，照 AgentSense 最新代码 `web/src/ui/ZoomHistory.tsx` 的 runs 折叠）：组的详情、展开后的列表里，连续 3 次以上、都顺利执行的同一个工具只留第一条，下面挂"还有 N 次同样的操作，都在授权内 ▾"，点开才逐条显示；默认收起。
- [ ] **回复**：只显示第一段，后面有内容时给"展开 ▾ / 详情 ›"。
- [ ] **思考**：默认一行"💭 ……（点开看）"，加"详情 ›"。
- [ ] **用户气泡**：可以点。
- [ ] **展开标记**：凡是有详情的条目都带 › 或 ▾。
- [ ] **语音气泡**：照旧，沿用 36 号票的同框。
- [ ] **测试**：前端状态层回放测试，覆盖各种条目的显示形态。
- [ ] **和 AgentSense 不一致的地方先问用户**。用户要的汇总行是在 AgentSense 之上加的。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。

## Notes

- 汇总行和详情里的工具，先用"工具中文名 + 参数摘要"描述。给常用工具写说人话的句子，以后单开一票（调研 §6.3）。
