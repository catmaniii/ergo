# 09 — 多媒体消息

Status: ready-for-agent
Blocked by: 04（秘书聊天最薄端到端）
Spec: [第一阶段规格](../spec.md) 第 5 节（前端协议）、第 7 节（秘书）、第 18 节（数据目录与备份）、第 21 节（实现细节补充）

## What to build

用户在秘书页给秘书发图片和文件，秘书的回复也能带图片和文件（比如它在草稿区算好的表、生成的图）。大文件走分片续传：网断了接着传，不用从头来，收尾时用 sha256 校验原始上传的字节。媒体按 sha256 只存一份，下载支持 Range；图片入库时剥掉 EXIF，剥过的才是入库版本，消息和素材引用的都是它的哈希。秘书页往上滚动时按页加载更早的历史。

发给模型之前，消息经过一个带版本号的纯函数投影：卡片换成一行摘要；图片按模型能力投影，不支持视觉的模型看到"[图片：文件名]"；文本类文件（含 markdown、代码、CSV）内联前 32 KB，PDF 先抽取文本再同样处理，其他类型只给文件名、类型和大小；语音换成转写（第一阶段只预留）。投影规则固定，保证提示词前缀稳定。要读附件全文，agent 用"读取附件"工具，只能读自己会话里的附件。

## Acceptance criteria

- [ ] 分片续传上传（自定义协议）：建上传 → 按偏移写分片 → 带 sha256 收尾，收尾校验的是原始上传字节的 sha256。主切面：上传到一半断开，重新连上后从服务端已收到的偏移继续，不重传已收到的字节；收尾的 sha256 不符时拒绝、不入库；超过单文件上限（默认 200 MB，可配置）在建上传时就被拒。
- [ ] 媒体按入库版本的 sha256 存在数据目录的素材区，同样的内容只存一份；下载支持 Range（返回 206 和正确的字节段）；第一阶段不生成缩略图等派生物。
- [ ] 图片入库时剥掉 EXIF：上传一张带 GPS 信息的 JPEG，下载回来的文件里没有 EXIF。剥过 EXIF 的是入库版本：收尾校验用原始字节的 sha256，入库和下载用剥过之后的内容，消息里的图片 part 和素材引用的都是入库版本的哈希（测试断言两个哈希不同、引用的是后者）。
- [ ] 用户 → 秘书：秘书页能选图片和文件发送，显示上传进度，断网恢复后接着传，在手机竖屏宽度下可用；消息带图片 part 和文件 part；聊天里图片直接显示、文件可以下载；多个前端同步看到。
- [ ] 秘书 → 用户：秘书能把草稿区里的文件作为附件发进聊天，文件复制进媒体库长期保留；之后删掉草稿区里的原文件，聊天里的附件照样能下载。
- [ ] 发给模型前的投影是带版本号的纯函数：卡片引用 → 一行摘要；图片 → 模型支持视觉时作为图片输入，不支持时为"[图片：文件名]"（模型能力从配置读）；文本类文件（含 markdown、代码、CSV）→ 内联前 32 KB，超出的部分提示用"读取附件"工具读；PDF → 先抽取文本，再按文本类处理；其他类型 → 只给文件名、类型和大小；语音 → 转写（只预留）。同样的输入和版本，输出逐字节相同（快照测试，覆盖上面每一类）。
- [ ] "读取附件"工具：agent 用它按附件引用读全文（文本类读原文，PDF 读抽出的文本），只能读自己会话里的附件；读别的会话的附件被拒并说明原因。主切面（faux 剧本）：用户发一个超过 32 KB 的文本文件，秘书看到前 32 KB，调用"读取附件"读到全文；伪造一个别的会话的附件引用去读，被拒。
- [ ] 历史分页：HTTP 接口按页返回某个会话更早的消息；分页结果和 WebSocket 上的事件在交界处不重不漏。秘书页往上滚动时加载更早的历史。
- [ ] 产生对应的素材事件：用户消息事件的负载里带附件引用（入库版本的 sha256、文件名、类型），够 08 号票把附件记为"外部、不可信"的引用加内容哈希。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。

## Notes

- 不在本票：外网端口上的鉴权和 nginx 放大 `client_max_body_size`（10）；备份里媒体按哈希只存一份（11）；聊天附件菜单里的"作为材料投喂"（21，复用本票的上传）；维护者会话里的附件随这些会话出现时（13、16）复用本票的机制和"读取附件"工具；语音、TTS 音频、视频 part 只预留。
- 被素材引用的媒体永不回收；本票不做媒体回收。
- 草稿区和它的围栏在 07 号票，本票不依赖 07。07 未完成时，"秘书发附件"这条用例直接往草稿区目录放文件来测；07 落地后，这个发附件的工具照常经守卫。
- 附件存在素材区，在秘书的围栏（草稿区、只读项目档案）之外。agent 读附件只走"读取附件"工具，按附件引用读、不按路径读，所以不落入"越出项目目录"；它在工具注册表（03）里标"只读或幂等"、不落入任何类别，"只能读自己会话里的附件"由这个工具自己保证。
