# 25 — 时间线缩放与活动状态

Status: ready-for-agent
Blocked by: 07（秘书草稿区、守卫接入与审批）, 13（任务执行与阶段验收）
Spec: [第一阶段规格](../spec.md) 第 19 节（Web UI）、第 5 节（前端协议）、第 2 节（守护进程的模块）、第 9 节（守卫）、第 21 节（实现细节补充）

## What to build

秘书聊天和维护者会话共用的会话组件，可以从完整视图缩放到要点层和全局层。要点层只留关注类别命中、审批、偏离、验收这类要点；全局层把会话聚成色块：任务的维护者会话按阶段着色，项目维护者会话按工单段着色，秘书主线按天着色。两层都单独标出命中关注类别的操作、通用 bash 调用、范围变更和越界记录；授权内的、做完告诉我的、被拦下或问过的操作用三种不同的样式，扫一眼就知道发生了什么。

活动状态频道实时推送每个 agent 此刻在做什么：休眠、干活中（附带在做什么）、等你、排队。任务看板的任务卡和项目列表的每个项目上用小圆点显示对应维护者的活动状态。活动状态和任务状态、项目状态是三回事，互不影响。

演示：打开一个跑过几个阶段的任务详情，把会话组件拨到要点层，只剩审批、关注类别命中、通用 bash 和验收这些要点，样式各不相同；再拨到全局层，看到按阶段的色块；打开一个项目的维护者会话拨到全局层，看到按工单段的色块；切到秘书页拨到全局层，看到按天的色块。同时看任务看板，维护者被唤起、等审批、闲置退出时，任务卡上的小圆点跟着变。

## Acceptance criteria

- [ ] 前端状态层回放（用主切面录下的事件流）：同一段会话投影到要点层时，只剩关注类别命中、审批、偏离、验收、通用 bash、范围变更和越界这些要点，其余条目收起；投影到全局层时，任务的维护者会话按阶段、项目维护者会话按工单段（16 号票的对话段也各成一块）、秘书主线按天聚成色块，色块上仍标出这些要点。
- [ ] 前端状态层回放：工具调用的三种情形——授权内放行、做完告诉我、被拦下或问过——在要点层和全局层上得到三种不同的样式标记；每个通用 bash 调用在两层上都带"通用 bash"标记，带类型的特殊 bash 工具（28 号票）不带。
- [ ] 主切面：消息里的工具调用 part 带齐第 5 节列出的字段——工具名、参数摘要、命中的关注类别、判定、是否授权内、是否通用 bash——取自守卫判定的结果；其中"是否授权内"由本票加进 part。
- [ ] 前端状态层回放：范围变更和越界记录在要点层和全局层上被单独标出；若 18 号票尚未完成，用按共享协议 schema 构造的范围记录事件验证。
- [ ] 主切面：活动状态频道在 agent 被唤起、开始干活、等用户（审批或澄清）、排队、闲置退出时各推送状态事件；"排队"包括同时存活的子进程满 8 个时新的唤起在等名额（12 号票）；"干活中"附带在做什么的简短说明，这类更新按进度事件的节流，每 100 毫秒最多一次。
- [ ] 主切面：活动状态事件只出现在活动状态频道上，不引起任务状态或项目状态的迁移；任务或项目状态变化也不改写活动状态。
- [ ] 界面：秘书页、任务详情和项目页的会话组件上有缩放控件，能在完整、要点层、全局层之间切换；任务看板的任务卡和项目列表的每个项目上有活动状态小圆点，随活动状态频道实时变化，断线重连后按序号补齐。
- [ ] 前端状态层回放：快速动作的执行事件（21 号票的"操作记录"）在时间线上可见，要点层和全局层都标出。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。
