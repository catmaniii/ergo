# 67 — 工具调用写成说人话的一句

Status: ready-for-agent
Blocked by: 57（聊天区精简）
Spec: [第一阶段规格](../spec.md) 第 19 节"会话区照搬 AgentSense"；调研 `docs/research/15-agentsense-zoom-detail-task-modes.md` §6.3、§3 里 `ToolRow` 的说明

## What to build

照 AgentSense：工具调用不写"工具名 + 参数摘要"，写一句人话，比如"读了 src/app.ts""把改动提交到 main：修复登录超时""给张三发了邮件：周五开会"。AgentSense 每个场景有 `describe`，没有的才退回"工具中文名 + 参数值拼接"，截到 60 字。

- 给常用工具各写一句的模板：读、写、改、删、列目录、搜索、通用 bash（按拆出来的命令）、git 提交 / 推送 / 建仓库、联网读取、发消息 / 邮件、提醒、日历、看板、项目档案、附件和素材。MCP 工具和没写模板的照旧退回"工具中文名 + 参数摘要"。
- 用在：工具调用组的要点那一行和展开后的列表（57 号票）、详情页的标题（56 号票）、缩放的要点层（54 号票）。
- 被拦下、问过、拒绝、出错的照 AgentSense 加前缀（⛔ / ↩ / ⏸ / ✕），读了敏感数据的加 🔒。

## Acceptance criteria

- [ ] 一句话的生成是前端状态层的纯函数，按工具名查模板；有表格测试，每个模板至少一条，含参数缺失、路径很长时截断。
- [ ] 回放现有录像，工具调用的那一行都换成了人话，没有模板的退回原样。
- [ ] 和 AgentSense 不一致的地方先问用户。
- [ ] 所有测试通过（vitest），lint（oxlint）无报错。
