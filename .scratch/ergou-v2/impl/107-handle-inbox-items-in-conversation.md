# 107 — 待办里要我处理的事，在它所在的项目、任务会话里也能处理

Status: ready-for-agent
Blocked by: 无
Spec: [第一阶段规格](../spec.md) 第 19 节（Web UI）；105 号票（待办每项跳到来源）、104 / 88 号票（项目、任务整页）、13 号票（等你验收、卡住求助、失败后的抉择……）

## What to build

用户 2026-10-13 原话："项目阶段的一些确认通过验收啥的，现在完全是在待办里面才能做，我跳转到他那个项目的聊天框，反而没有那个确认的按钮，这个逻辑就很奇怪，应该是我可以在待办里面确认，我到项目里面当然也要可以确认了，怎么能只能在待办里面确认？不能在项目聊天框里确认呢？"

现在：卡片类事项（计划确认、立项书、审批卡、提问卡……）以 `card_ref` 出现在会话里，卡上有按钮；但**通知类事项**（`stage_acceptance` 等你验收、`stuck_help` 卡住求助、`failure_choice` 失败后的抉择、`over_budget` 超预算、`grant_renewal` 授权到期续期、`interrupted` 中断不确定、`hand_over` 交给我做、`out_of_scope` 越界、`project_delete` 删除项目的确认……）只在待办详情（`pages/InboxPage.tsx` 的 `NoticeView`）里有动作按钮，会话里看不到也点不了。105 号票的"去项目 ›""去任务 ›"跳过去之后，用户找不到要按的按钮。

改成：

- **会话里一条"等你处理"栏**：项目整页（维护者的会话）、任务整页（负责它的 agent 的会话）、秘书会话，把**还没处理的、来源是这个会话的待办事项**列在会话和输入框之间（固定在那里，不跟着对话滚走）。哪些事项属于这个会话，用 105 号票的 `inboxJump` 认（去处是这个任务 / 这个项目 / 秘书会话的），不另起一套规则。
  - 收着时一行：`等你处理 N 项` + 第一项的标题（放不下省略）+ 展开键；只有一项时这一行直接带它的动作按钮。
  - 展开后逐项列出：通知类事项带它在待办里的那组动作按钮（验收通过 / 退回、继续执行、重试 / 取消任务、追加预算继续……，和 `NoticeView` 同一份，抽成共用部件，不复制一份）；卡片类事项给"看卡片"，在会话里定位到那张卡（105 的 `revealAt`；卡在还没加载的更早历史里时照 105 的做法），卡上的按钮照旧在卡上。
  - 展开后最高占会话区的大约三分之一，多了在栏里滚动，不把对话整个盖住。
  - 处理走同一个请求（`inboxAction(..., "handle", choice)`），待办里那一项同时变成已处理，红点跟着少；处理完这一项从栏里消失，没有了整条栏不显示。
  - 需要写一句话的动作（比如退回要写原因，如果待办里是这样）在栏里也能写，和待办里一致。
- 待办详情里"去项目 ›""去任务 ›"跳过来时，栏里对应那一项默认展开、闪一下（能做到就做；做不到写在 Comments）。
- 归档了的项目会话只读，但"删除项目的确认"这类还要处理的照样显示可点。
- 缩小到要点层 / 全局层时栏照样在（或照缩放层的规矩收起，挑不挡内容的，写在 Comments）。
- 窄屏（390）和宽屏（1280，含项目档案栏开着、任务阶段栏开着）都不挡输入框、不横向溢出；11 套风格里输入框区域有自己样子的，栏的样子跟着协调（至少不突兀）。
- 108 号票同时在做：会话右下角会加"到最上面 / 到最下面"的浮动按钮，挨着输入框上沿；这条栏在输入框上面时，那两个按钮在栏的上面。两边合并时由主会话处理冲突，你这边只要留出位置、别把栏做成 `position: fixed` 盖住整个会话区。

## Acceptance criteria

- [ ] 项目整页、任务整页、秘书会话里都有"等你处理"栏，列出来源是这个会话、还没处理的事项；通知类事项能直接点动作，卡片类能定位到卡。
- [ ] 在栏里处理和在待办里处理是同一件事（同一个请求，两边一起变）；有状态层测试（哪些事项进哪个会话的栏、处理后消失、已处理 / 已归档的不进），优先用现有的录制回放（如 `task-rejections`、`task-over-budget`、`grant-renewal`）。
- [ ] 截图：经典浅色 390、1280 的项目整页（等你验收一项、收着 / 展开）、任务整页（多项展开），另挑 2 套风格。示例数据里不要出现日本相关的内容。
- [ ] 只动 Web：跑 web 包全量一次，typecheck、oxlint 通过；`docs/dev.md` 跟着改（"卡片和待我处理"那节）。
