## Question

二狗 Web UI 的"全景"页长什么样？用户要一眼看到整个系统此刻的样子，并且从这里点进任何一个会话。需要回答：

1. **画面怎么组织**：秘书、记忆管理者、每个维护者和子 agent 各是一个拟人化的小人。按什么摆放：按项目、按任务，还是像一间办公室里的工位？运营中、建设中、已停用的项目各自怎么呈现？
2. **状态怎么表现**：agent 的四种活动状态（休眠、干活中、等你、排队）各用什么动画；"干活中"怎样显示在做哪个任务、第几阶段；维护者头上怎样显示排着几张工单。
3. **交互**：点小人进入它的会话；点项目进项目页；点任务进任务看板上对应的卡。和"待我处理"的小红点怎样呼应。
4. **手机竖屏**上怎样降级。

做一个粗原型（可以点击、带假数据的动画页面）供评审，原型作为附件链接在本票里。

## Context

- 用户 2026-10-07（「项目生命周期、工作空间与维护者」第 1 轮新增 Q11）：要一个全局的可视化总览，拟人化、带动画；能看到哪些 agent 在做什么任务、哪些项目在运营（agent 未激活）、哪些在开发（agent 在干活）；点击其中一个就进入相应的会话。
- 「项目生命周期、工作空间与维护者」已定：
  - agent 活动状态有休眠、干活中、等你、排队四种，由运行时实时上报；
  - 第一阶段只在任务看板和项目列表上用小圆点显示；全景页放第二阶段；
  - 读记忆不经过记忆管理者，所以读记忆不会让它"动起来"。
- 「Web UI 信息架构」给全景留入口。名字叫"全景"，不叫"看板"（"看板"已指任务看板）。
- 视觉语言继承 AgentSense，见 `docs/research/01-ref-agentsense.md` §5、§7。
