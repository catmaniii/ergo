## Answer

2026-10-07 定稿。

### 1. 服务登记（LSM）

- **只登记两个服务**，都在 LSM 里注册、由 LSM 启动：
  - **`ergou-daemon`**：守护进程。
    - 健康探针 `/healthz`；
    - 接入 LSM 的 link 协议，心跳里上报"忙"（有任务在跑时），LSM 可以按"空闲时再重启"处理（`docs/research/08-local-infra.md` §3.2）；
    - 开 autoRestart；
    - 用一个专用的、固定版本的 Node 22 LTS，在 LSM 条目里写绝对路径；
    - 密钥由 LSM 从 `secrets/` 注入（`env.from: file`）；
    - 语音服务（audio.cpp、将来的 ASR）作为软依赖：不在线时语音功能降级，守护进程照常运行。
  - **`ergou-tunnel`**：照抄 `agentsense-tunnel`，换端口。密钥路径照抄现有隧道里的写法，不用 `manager.yaml` 里那个坏路径（`docs/research/08-local-infra.md` §3.8）。隧道只连守护进程的**外网端口**。
- **agent 子进程不是服务**：秘书、维护者、子 agent 每个一个子进程（「运行时架构」），由守护进程启停，放进二狗自建、不允许脱离的 Job 对象。它们不对外监听端口，不在 LSM 登记；守护进程被 LSM 重启时一起清掉。这不违反"服务只能由 LSM 启动"的规矩。
- **公网上线前**先修好 LSM 的两个已知问题：隧道 PID 复用导致的误判，以及 `vps.key` 路径错误（`docs/research/08-local-infra.md` §3.8）。

### 2. 访问与 HTTPS

- **PC 本机**：浏览器走 localhost 的**本机端口**。
- **其他设备**（安卓、鸿蒙、笔记本）：一律走 VPS 上的 HTTPS 公网域名，在家也绕一次 VPS。域名照现有惯例取 `ergou.<VPS>.sslip.io`（`docs/research/08-local-infra.md` §3.4）。不做局域网直连和自签证书。
- **两个监听端口**（「消息协议与多前端」）：本机端口只监听 127.0.0.1、自动信任；外网端口是隧道的目标、永远不享受本机信任。两个端口都提供 API、WebSocket 和 Web UI。
- **证书**：沿用 VPS 上现有的 Let's Encrypt 做法。
- **nginx 站点**：
  - 由二狗生成配置：支持 WebSocket，`client_max_body_size` 放大，`proxy_read_timeout` 加长；每个 location（包括 WebSocket 的）都覆盖写 `X-Forwarded-For`、`X-Real-IP`；加 HSTS。
  - 你授权一次，由二狗 ssh 上 VPS 代办部署。这算对外操作，照关注类别先问你。
  - VPS 上的隧道端口只绑 VPS 本机地址。

### 3. 数据目录

放在 `C:\Users\catmaniii\.ergou\`。不放 D、E 盘，因为盘根对所有登录用户开放修改；用户目录只有你本人、系统和管理员能访问。

| 目录 | 放什么 |
|---|---|
| `config/` | 配置；MCP 登记；关注类别注册表 |
| `secrets/` | 密钥。只由 LSM 注入，agent 读不到 |
| `db/` | `ergou.db`：事件日志，以及由它派生的看板、审批、工单、提醒、token 账本；`memory.db`：记忆库，只由记忆模块写 |
| `sessions/` | 各 agent 的 pi 会话（JSONL） |
| `projects/<项目名>/` | 项目档案；工作目录默认也在这里 |
| `tasks/<任务>/` | 不属于任何项目的任务的产出，随任务保留 |
| `materials/` | 素材原文和媒体，媒体按内容哈希存 |
| `skills/` | 你自己加的、或从别处导入的 skill，按项目或任务授权 |
| `tmp/` | 临时文件，守护进程每天清理 7 天前的 |
| `backups/` | 本机备份快照 |
| `logs/` | 日志 |

- **落盘规矩**：
  - 任何 agent 只能写分配给它的那一格，不能自己建顶层目录；
  - 守护进程的文件工具有路径围栏，越界的写入由守卫拦下。
- **密钥保护**：
  - 守卫拒绝读取 `secrets/`；
  - agent 子进程只注入它需要的模型 key；
  - bash 等工具起的孙进程，环境变量里剥掉所有密钥。
- **框架和个人数据的边界**：二狗仓库只放代码、框架自带的 skill 和示例配置；数据目录的路径从配置读，不写死。
- **外部工作目录**：项目绑定的外部工作目录不随二狗备份，靠项目自己的 git 远端。

### 4. 备份

- **第一阶段就做。** 写到华为家庭存储的同步目录，是往一个普通文件夹里写，不需要 SMB 账号。
- **调度**：在守护进程内的调度器里，每晚一次。不用 Windows 计划任务。
- **步骤**：
  1. 在本机做一致性快照，写到 `backups/<日期>/`：
     - SQLite 用 `VACUUM INTO`；
     - 其他文件增量复制；
     - 媒体按内容哈希只存一份。
     
     本机保留最近 7 份。
  2. 把快照复制到 `C:\吴同学-E898DC\华为家庭存储\手机备份\Ergou_projects\<日期>\`，由华为的同步客户端同步到家庭存储。同步目录里保留每日 7 份、每周 4 份。
- **按日期分目录、保留多份**：因为同步不是备份，本地坏了会被同步过去，只有多份历史才能退回。
- **不加密**：你在知道"同步根对本机所有账户开放、家庭成员可能看得到"之后选的。
- **不进备份**：
  - `secrets/`：API key 等由你自己在密码管理器里留一份；
  - `tmp/`；
  - 外部工作目录。
- **失败处理**：写入失败（目录不在、空间不够、复制出错）时，在"待我处理"放一条事项。
  - 二狗只能确认"已写进同步目录"，看不到华为客户端有没有同步到家庭存储。

### 5. 重启后没人登录

- **接受停机**：Windows 夜里更新重启后，在你登录之前，二狗一直不在线。
- **不开自动登录。**
- **登录后补发**：你登录后 LSM 拉起守护进程，调度器按规则补发错过的提醒和作业（补发阈值见「运行时架构」）。

### 6. 留给规格（默认做法）

- `ergou-daemon.yaml` 和 `ergou-tunnel.yaml` 的完整条目；两个端口的端口号；隧道 remotePort 的选取；
- nginx 站点模板；
- 数据目录各格的子结构，以及配置项名称；
- 快照的一致性做法（pi JSONL 会话是追加写，复制时容忍最后半行）；
- 备份保留策略的数值；
- 恢复：一条恢复命令，并定期自动校验最新快照（打开数据库、做完整性检查），失败进"待我处理"；
- `tmp/` 清理周期。
