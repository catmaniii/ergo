# 关注类别与打扰策略

Type: grilling
Status: open

## Question

用户怎样为长程任务和项目指定"哪些操作要提醒我"？需要定下来的问题：

1. **关注类别注册表**：结构是什么（匹配条件、属性、处置档位）？
2. **默认值**：默认带哪些类别？哪些底线不允许用户放宽？
3. **授权与确认**：计划期给出的、带边界的授权（grant），和运行时的确认是什么关系？
4. **打扰控制**：打扰预算、汇总推送、免打扰时段，以及超时后的默认处理。
5. **呈现**：这些类别在全局层和要点层视图上怎样展示？

## Context

- `docs/research/01-ref-agentsense.md` §6：AgentSense 写死的安全类别（这是要泛化的地方），以及建议的"关注类别注册表"。
- `docs/research/06-long-tasks-hitl-interruptions.md`：处置档位、带边界的授权、打扰预算。
- 关注类别不限于安全，由用户指定（立项需求 2）。
- 「记忆边界」已定，本票需要落实：
  - "访问授权外的个人记忆"是一个关注类别：任务执行中要用记忆范围以外的记忆时，提醒用户临时授权。
  - 记忆范围是带边界授权的一种，在用户确认计划时一并授予。
  - 计划卡上要展示两件事：这份计划引用了哪些记忆，以及执行中可能调用的记忆范围。
  - "了解你"问题永远不推送，不占打扰预算；只有任务澄清走审批和推送通道。
- 「任务生命周期与任务看板」已定：
  - 快速动作要不要用户确认，由关注类别决定。
  - Web UI 有一个"待我处理" tab，汇集所有要用户注意或确认的事项，未读时亮小红点；秘书不在对话里主动转述。本票定哪些事项进"待我处理"、哪些还要推送。
  - "了解你"问题不进"待我处理"。
