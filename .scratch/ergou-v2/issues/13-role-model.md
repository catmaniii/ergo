# 角色模型：角色卡、领域边界与经验沉淀

Type: grilling
Status: open
Blocked by: 02

## Question

1. **角色怎么定义**：角色卡用什么格式？可参考 Claude Code 的 `agents/*.md` 和 OpenClaw specialist lane 的契约。一张角色卡写明：
   - 目的；
   - 非目标；
   - 工具清单；
   - 能看到的记忆范围；
   - 预算；
   - 交接方式。
2. **怎样在代码里强制"只做本领域的事"**：工具白名单；越界时拒绝并上报。
3. **角色经验怎样沉淀**：
   - 运行中只写项目笔记；
   - 结项时做增量合并；
   - 经验先进候选，经审批后转正；
   - 每条经验标注来源；
   - 防止跨项目污染。
4. **角色怎样增删改查**：包括出现新需求时，由秘书提议新增角色。
