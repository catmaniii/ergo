# 推送与远程审批通道

Type: grilling
Status: open
Phase: 2（暂缓，第一阶段规格之后再做）

## Question

二狗怎样把系统级通知送到手机？用户离开电脑时，怎样安全地完成审批？需要定下：

1. **各平台的推送方案**
   - 鸿蒙 Push Kit：WORK 分类；推送通知没有按钮；审批要点开 App，经生物识别和设备密钥签名后提交。
   - Android：用 ntfy 或 UnifiedPush。
   - Web Push。
2. **通知服务的抽象**：内部事件怎样映射到通知类别。
3. **多渠道答复**：同一件事从多个渠道答复时怎样去重，答复后怎样撤回其他渠道上的通知。
4. **掉线报警**：守护进程掉线时怎样报警。
